Matplotlib is a Python visualization library used to explore data, understand distributions, compare groups, inspect model results, and communicate findings.

## Core concepts

-   **Figure:** The whole canvas.
-   **Axes:** One plotting area inside a figure.
-   **Axis:** The x- or y-scale, ticks, and tick labels.
-   **Artist:** A visual element such as a line, label, or legend.

``` python
fig, ax = plt.subplots(figsize=(8, 5))  # Figure and one axes
ax.plot([1, 2, 3], [10, 20, 15])
ax.set(title="My First Plot", xlabel="X", ylabel="Y")
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()
```

### Pyplot vs object-oriented style

``` python
plt.plot([1, 2, 3], [2, 4, 3])  # Quick plot
plt.title("Quick Plot")
plt.show()
```

``` python
fig, ax = plt.subplots()        # Preferred for complex plots
ax.plot([1, 2, 3], [2, 4, 3])
ax.set_title("Object-Oriented Plot")
plt.show()
```

## Standard plotting workflow

-  Create a figure and axes.
-  Plot the data.
-  Add a title, axis labels, and legend.
-  Set scales, ticks, and limits.
-  Adjust layout.
-  Display or save the figure.

``` python
fig, ax = plt.subplots(figsize=(9, 5), dpi=120)
ax.plot([1, 2, 3, 4], [10, 18, 15, 25],
        color="royalblue", linewidth=2, marker="o", label="Observed")
ax.set(title="Sample Results", xlabel="Observation", ylabel="Value")
ax.legend()
ax.grid(True, linestyle="--", alpha=0.3)
fig.tight_layout()
plt.show()
```

## Figure size and layout

``` python
fig, ax = plt.subplots(figsize=(10, 6))                 # Size in inches
fig, ax = plt.subplots(figsize=(10, 6), dpi=150)         # Resolution
fig, axes = plt.subplots(2, 2, layout="constrained")     # Multi-plot layout
```

## Main plot types

### Line plot --- trends and time series

``` python
x = [1, 2, 3, 4, 5]
y = [10, 15, 13, 20, 25]

fig, ax = plt.subplots()
ax.plot(x, y, marker="o", linewidth=2)
ax.set(title="Trend", xlabel="Time", ylabel="Value")
plt.show()
```

### Scatter plot --- relationships between numerical variables

``` python
height = [150, 160, 170, 180, 190]
weight = [50, 58, 65, 78, 90]

fig, ax = plt.subplots()
ax.scatter(height, weight, s=70, alpha=0.8)
ax.set(xlabel="Height (cm)", ylabel="Weight (kg)")
plt.show()
```

Useful scatter options: `s` marker size, `alpha` transparency, `c` color
or numeric values, `marker` shape, `edgecolors` outline.

### Vertical and horizontal bar charts --- category comparisons

``` python
labels = ["A", "B", "C", "D"]
values = [25, 40, 30, 55]

fig, ax = plt.subplots()
bars = ax.bar(labels, values, color="steelblue")
ax.bar_label(bars, padding=3)  # Add values above bars
plt.show()

fig, ax = plt.subplots()
ax.barh(labels, values)        # Horizontal bars suit long labels
plt.show()
```

### Grouped bars

``` python
labels = ["A", "B", "C"]
a, b = [20, 35, 30], [25, 30, 40]
x = np.arange(len(labels))
width = 0.35

fig, ax = plt.subplots()
ax.bar(x - width/2, a, width, label="Group A")
ax.bar(x + width/2, b, width, label="Group B")
ax.set_xticks(x, labels)
ax.legend()
plt.show()
```

### Stacked bars

``` python
fig, ax = plt.subplots()
ax.bar(labels, a, label="A")
ax.bar(labels, b, bottom=a, label="B")
ax.legend()
plt.show()
```

### Histogram --- distribution of one numeric variable

``` python
rng = np.random.default_rng(42)
data = rng.normal(loc=50, scale=10, size=1000)

fig, ax = plt.subplots()
ax.hist(data, bins=30, edgecolor="black", alpha=0.8)
ax.set(xlabel="Value", ylabel="Frequency", title="Distribution")
plt.show()
```

Histogram options: `bins=20`, `bins="auto"`, `density=True`,
`cumulative=True`, `histtype="step"`.

### Box plot --- median, quartiles, and potential outliers

``` python
groups = [
    np.random.default_rng(1).normal(50, 8, 200),
    np.random.default_rng(2).normal(60, 12, 200)
]
fig, ax = plt.subplots()
ax.boxplot(groups, tick_labels=["A", "B"], showmeans=True)
plt.show()
```

Points beyond whiskers are potential outliers, not automatically errors.

### Violin plot --- distribution shape

``` python
fig, ax = plt.subplots()
ax.violinplot(groups, showmeans=True, showmedians=True)
ax.set_xticks([1, 2], ["A", "B"])
plt.show()
```

### Pie chart --- parts of a whole (use sparingly)

``` python
fig, ax = plt.subplots()

       autopct="%1.1f%%", startangle=90)
```

## Colors, lines, and markers

``` python
ax.plot(x, y, color="red")              # Named color
ax.plot(x, y, color="#3366CC")           # Hex color
ax.plot(x, y, linestyle="-")             # Solid
ax.plot(x, y, linestyle="--")            # Dashed
ax.plot(x, y, linestyle="-.")            # Dash-dot
ax.plot(x, y, linestyle=":")             # Dotted
ax.plot(x, y, marker="o")                # Circle
ax.plot(x, y, marker="s")                # Square
ax.plot(x, y, marker="^")                # Triangle
ax.plot(x, y, markersize=7, linewidth=2)
ax.scatter(x, y, s=80, alpha=0.6)        # Size and transparency
```

Useful marker options include `"o"`, `"s"`, `"^"`, `"x"`, `"+"`, `"*"`,
and `"."`. Use consistent, accessible colors; do not encode important
meaning by color alone.

## Axis limits, ticks, and scales

``` python
ax.set_xlim(0, 10)                       # X-axis range
ax.set_ylim(0, 100)                      # Y-axis range
ax.set_xticks([0, 2, 4, 6, 8, 10])       # Tick positions
ax.set_xticks([1, 2, 3], ["Low", "Mid", "High"])  # Custom labels
ax.tick_params(axis="x", labelrotation=45)
ax.invert_yaxis()                        # Reverse y-axis
```

### Log scales

``` python
ax.set_xscale("log")  # Logarithmic x-axis
ax.set_yscale("log")  # Logarithmic y-axis
ax.semilogx(x, y)     # Log x-axis
ax.semilogy(x, y)     # Log y-axis
ax.loglog(x, y)       # Both axes logarithmic
```

Log scales generally require positive values. Make the scale clear to
readers.

### Tick formatters

``` python
from matplotlib.ticker import MultipleLocator, StrMethodFormatter, PercentFormatter

ax.xaxis.set_major_locator(MultipleLocator(5))       # Ticks every 5 units
ax.yaxis.set_major_formatter(StrMethodFormatter("${x:,.0f}"))  # Currency
ax.yaxis.set_major_formatter(PercentFormatter(xmax=1))          # 0 to 1 proportions
```

For data stored as `25` rather than `0.25`, use
`PercentFormatter(xmax=100)`.

### Scatter plot with linear trend

``` python
rng = np.random.default_rng(42)
xdata = np.arange(1, 101)
ydata = 2.5*xdata + rng.normal(0, 20, len(xdata))
slope, intercept = np.polyfit(xdata, ydata, 1)

fig, ax = plt.subplots()

```

A trend line does not establish causation or prove a linear model is
appropriate.

## Missing values and plotting gaps


Do not fill missing values only to make a plot look continuous. Choose a
method that suits the analysis.

## Large datasets and performance

-   Use vectorized NumPy/Pandas operations to prepare data.
-   Use transparency in dense scatter plots.
-   Sample points if plotting every observation is unnecessary.
-   Aggregate data when it fits the question.
-   Use hexbin plots for dense two-dimensional data.
-   Close figures created in loops.

### Hexbin density plot

``` python
rng = np.random.default_rng(42)
xdata = rng.normal(size=100_000)
ydata = 0.5*xdata + rng.normal(size=100_000)

fig, ax = plt.subplots()

fig.colorbar(hb, ax=ax, label="Count")
plt.show()
```

### Sample a DataFrame


### Close figures in loops

``` python
for i in range(5):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [i, i+1, i+2])
    fig.savefig(f"plot_{i}.png")
    plt.close(fig)  # Release figure resources
```

  `ax.bar()` / `ax.barh()`                Vertical / horizontal bars
  `ax.hist()`                             Histogram
  `ax.boxplot()`                          Box plot

  `ax.errorbar()`                         Error bars
  `ax.fill_between()`                     Fill between curves
  `ax.imshow()`                           Display image or matrix
  `ax.hexbin()`                           Dense 2D distribution
  `ax.annotate()`                         Add annotation
  `ax.axhline()` / `ax.axvline()`         Reference lines
  `ax.set_xlim()` / `ax.set_ylim()`       Set axis limits
  `ax.set_xticks()` / `ax.set_yticks()`   Set ticks
  `ax.legend()`                           Display legend
  `fig.tight_layout()`                    Improve spacing
  `fig.savefig()`                         Save figure
  `plt.close()`                           Close figure

## Plot selection guide

  
  Question                            Recommended plot
  ----------------------------------- 
  How does a value change over time?  Line plot

  How do categories compare?          Bar chart

  What is a variable's distribution?  Histogram, box plot, violin plot

  Are two numeric variables           Scatter plot
  associated?                         

  Are there potential outliers?       Box plot, scatter plot

  How do group distributions compare? Box plot, violin plot, overlaid
                                      histograms

  How does a matrix vary?             Heatmap

  Where are many x-y observations     Hexbin plot
  concentrated?                       

  How well does regression predict?   Actual-vs-predicted, residual plot

  How does model loss evolve?         Training/validation curves

  What classification errors occur?   Confusion matrix

  How uncertain is an estimate?       Error bars or confidence band

## Final visualization checklist

-   [ ] The plot type fits the analytical question.
-   [ ] The title and axis labels are meaningful.

-   [ ] Legends identify relevant series.

## Best practices to remember

-   Prefer the object-oriented interface for maintainable plotting code.
-   Select the plot for the question, not just for decoration.
-   Label units and explain transformations.
-   Use consistent styling across reports.
-   Use subplots for related comparisons.
-   Save publication-quality figures with appropriate resolution.
-   Matplotlib visualizes data; use NumPy, Pandas, SciPy, or
    scikit-learn for data preparation and statistical calculations.
