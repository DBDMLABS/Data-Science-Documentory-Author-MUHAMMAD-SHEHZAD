### Detecting Outliers with IQR

```bash
df["Salary"].quantile(0.5)  # Calculate median

df["Salary"].quantile(
    [0.25, 0.5, 0.75]
)  # Calculate quartiles

Q1 = df["Salary"].quantile(0.25)  # First quartile
Q3 = df["Salary"].quantile(0.75)  # Third quartile

IQR = Q3 - Q1  # Interquartile range

lower = Q1 - 1.5 * IQR  # Lower boundary
upper = Q3 + 1.5 * IQR  # Upper boundary

outliers = df[
    (df["Salary"] < lower) |
    (df["Salary"] > upper)
]  # Select potential outliers
```
