## 1. Data Types

**Purpose:** Data types decide how Python stores a value and which operations are allowed on it. In data science, they help you tell apart measurements, text, categories and missing values.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Data type | Defines the kind of value an object holds. | Decides which calculations and transformations are valid. |
| `int` | Whole number, such as `25`. | Counts records, students or transactions. |
| `float` | Floating-point (decimal) number, such as `72.5`. | Measurements, averages and predictions. |
| `complex` | Number with real and imaginary parts, such as `3 + 4j`. | Signal processing and scientific computing. |
| `str` | Text string, such as `"Ali"`. | Names, labels, reviews and text analysis. |
| `bool` | `True` or `False`. | Filtering records and testing conditions. |
| `list` | Ordered, mutable sequence: `[1, 2, 3]`. | Storing observations or features. |
| `tuple` | Ordered, immutable sequence: `(3, 4)`. | Fixed coordinates and configuration values. |
| `set` | Unordered collection of unique, hashable elements: `{1, 2}`. | Finding distinct categories. |
| `dict` | Key-value collection that keeps insertion order (Python 3.7+). | Representing structured records and settings. |
| `None` | Represents the absence of a value (type `NoneType`). | Marking missing or unavailable information. |
| `type()` | Returns an object's type. | Inspecting imported values. |
| `isinstance()` | Checks whether an object is an instance of a type (or its subclass). | Validating function inputs. |
| Type conversion | Converts a value from one type to another: `int()`, `float()`, `str()`. | Turning imported numeric strings into numbers. |
| Mutable | Object whose contents can change (`list`, `dict`, `set`). | Updating lists and dictionaries. |
| Immutable | Object whose contents cannot change (`int`, `float`, `str`, `tuple`). | Representing fixed values; can be dictionary keys. |
| Indexing | Accesses an item by position, starting at `0`. | Retrieving a particular observation. |
| Slicing | Selects a portion of a sequence: `seq[start:stop:step]` (stop is excluded). | Taking a subset of data. |

### Example: Data Types

```python
age = 25                        # int
height = 72.5                   # float
z = 3 + 4j                      # complex
name = "Ali"                    # str
passed = True                   # bool
scores = [80, 85, 90]           # list
point = (3, 4)                  # tuple
cities = {"Lahore", "Karachi", "Lahore"}   # set (duplicate removed)
student = {"name": "Ali", "age": 25}       # dict
missing = None                  # NoneType

print(type(height))             # <class 'float'>
print(isinstance(age, int))     # True
print(len(cities))              # 2
print(int("42") + 1)            # 43
print(scores[0], scores[-1])    # 80 90
print(scores[0:2])              # [80, 85]
print(z.real, z.imag)           # 3.0 4.0
```

> **Note:** `bool` is a subclass of `int`, so `isinstance(True, int)` is `True` and `True + True` is `2`. This is why `sum([True, False, True])` counts the `True` values (`2`).

> **Remember:** Data type = what kind of value is this?

## 2. Variables

**Purpose:** Variables give names to values so that datasets, calculations and model settings can be reused.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Variable | Name that refers to an object. | Stores datasets and results. |
| Assignment `=` | Binds a name to a value. | Saves an average or a prediction. |
| Identifier | Valid name for a variable, function or class (letters, digits, `_`; cannot start with a digit). | Makes analysis code understandable. |
| Naming convention | Consistent naming style (see PEP 8). | Improves project readability. |
| `snake_case` | Lowercase words separated by underscores. | Variable and function names such as `average_salary`. |
| `PascalCase` | Capitalized words joined together. | Class names such as `DataCleaner`. |
| Keyword | Reserved Python word, such as `if`, `for`, `class`. | Cannot be used as an identifier. |
| Dynamic typing | A name can refer to objects of different types over time. | Supports exploratory programming. |
| Multiple assignment | Assigns several names in one statement: `x, y = 1, 2`. | Sets analysis parameters together. |
| Unpacking | Assigns collection elements to separate names. | Separates coordinates or returned results. |
| Constant | Value intended not to change, written in `UPPER_CASE` (by convention only). | Stores fixed thresholds and settings. |
| Local variable | Name defined inside a function. | Holds temporary calculations. |
| Global variable | Name defined at module (file) level. | Holds shared configuration when appropriate. |
| Scope | Region where a name can be accessed (LEGB: Local, Enclosing, Global, Built-in). | Prevents accidental interference between functions. |
| `global` | Allows a function to assign to a module-level name. | Occasionally manages shared state; usually avoidable. |
| `del` | Deletes a name binding or a collection item. | Removes unwanted dictionary entries. |

### Example: Variables and Scope

```python
x, y = 10, 20                   # multiple assignment
a = b = 0                       # same value to two names
px, py = (3, 4)                 # unpacking
first, *rest = [1, 2, 3, 4]     # extended unpacking
print(first, rest)              # 1 [2, 3, 4]

THRESHOLD = 0.5                 # constant (by convention)

counter = 0                     # global variable

def increase():
    global counter              # needed to change the global name
    counter += 1

increase()
print(counter)                  # 1

record = {"name": "Ali", "temp": 99}
del record["temp"]
print(record)                   # {'name': 'Ali'}
```

> **Important Point:** Assignment does not copy an object. After `b = a` where `a` is a list, `a` and `b` point to the **same** list, so changing `b` also changes `a`. Use `b = a.copy()` when you need a separate list.

> **Remember:** Variable = a name that refers to a value or object.

## 3. Numbers and Math

**Purpose:** Numerical operations support statistics, feature engineering, error measurement and machine learning.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Addition `+` | Adds numbers. | Calculates totals. |
| Subtraction `-` | Finds a difference. | Measures prediction error. |
| Multiplication `*` | Multiplies numbers. | Scales features and applies weights. |
| Division `/` | Divides and always returns a `float`. | Calculates means, ratios and percentages. |
| Floor division `//` | Divides and rounds down (towards negative infinity). | Calculates complete groups or batches. |
| Modulus `%` | Returns the remainder. | Selects every nth observation. |
| Exponentiation `**` | Raises a number to a power. | Computes squared errors and polynomial features. |
| Operator precedence | Rules for the order of operations: `**`, then `*` `/` `//` `%`, then `+` `-`. | Evaluates formulas correctly. |
| Augmented assignment `+=` | Updates a variable using an operation (`-=`, `*=`, `/=` also exist). | Accumulates totals. |
| `abs()` | Returns the absolute value. | Computes absolute prediction error. |
| `round()` | Rounds a number to a given number of decimals. | Formats reported results. |
| `pow()` | Raises a number to a power: `pow(2, 3)` is `8`. | Calculates growth and polynomial terms. |
| `divmod()` | Returns `(quotient, remainder)`. | Calculates groups and leftovers. |
| `min()` | Returns the smallest value. | Finds the minimum measurement. |
| `max()` | Returns the largest value. | Finds the maximum measurement. |
| `sum()` | Adds an iterable of numbers. | Calculates totals and means. |
| `math` | Standard-library mathematics module. | Provides mathematical functions and constants. |
| `math.sqrt()` | Returns a square root (as a `float`). | Calculates distance, standard deviation and RMSE. |
| `math.floor()` | Rounds down to an integer. | Defines lower interval boundaries. |
| `math.ceil()` | Rounds up to an integer. | Determines the number of batches needed. |
| `math.pi` | Approximation of π (3.141592653589793). | Geometry and scientific formulas. |
| Floating-point precision | Limited accuracy of binary floating-point numbers. | Explains small numerical differences such as `0.1 + 0.2`. |
| Tolerance | Acceptable numerical difference. | Compares approximate calculations. |
| `math.isclose()` | Compares numbers using relative and absolute tolerance. | Tests results affected by rounding. |
| `abs_tol` | Fixed absolute tolerance (default `0.0`). | Compares values near zero. |
| `rel_tol` | Tolerance relative to the size of the values (default `1e-09`). | Compares values at different scales. |
| `decimal` | Decimal arithmetic with controlled precision. | Financial calculations. |
| `random` | Pseudorandom number generation module. | Sampling, simulation and randomized experiments. |

### Example: Operators and Precedence

```python
import math

print(7 / 2)          # 3.5
print(7 // 2)         # 3
print(-7 // 2)        # -4   (rounds down, not towards zero)
print(7 % 2)          # 1
print(2 ** 3)         # 8
print(divmod(17, 5))  # (3, 2)

print(2 + 3 * 4)      # 14   (* before +)
print((2 + 3) * 4)    # 20
print(-2 ** 2)        # -4   (** before the minus sign)

total = 0
total += 5
print(total)          # 5

print(abs(-3.2))                  # 3.2
print(min([4, 9, 1]), max([4, 9, 1]), sum([4, 9, 1]))   # 1 9 14
print(math.sqrt(25))              # 5.0
print(math.floor(3.7), math.ceil(3.2))   # 3 4
print(math.ceil(105 / 10))        # 11  (batches needed for 105 rows, 10 per batch)
```

### Example: Floating-Point Precision

```python
import math
import random
from decimal import Decimal

print(0.1 + 0.2)                      # 0.30000000000000004
print(0.1 + 0.2 == 0.3)               # False
print(math.isclose(0.1 + 0.2, 0.3))   # True

# Near zero, rel_tol alone is not enough — use abs_tol
print(math.isclose(1e-10, 0.0))                 # False
print(math.isclose(1e-10, 0.0, abs_tol=1e-9))   # True

# Exact decimal arithmetic (create Decimals from strings)
print(Decimal("0.1") + Decimal("0.2"))  # 0.3

# round() uses "banker's rounding": ties go to the nearest even number
print(round(2.5), round(3.5))         # 2 4
print(round(3.14159, 2))              # 3.14

# Reproducible random numbers
random.seed(42)                       # same seed -> same results every run
print(random.random())                # a float between 0.0 and 1.0
print(random.choice(["A", "B", "C"])) # one random item
```

> **Tip:** Never compare floats with `==`. Use `math.isclose()` (or `numpy.isclose()` for arrays).

> **Remember:** `sqrt()` = square root; `isclose()` = approximate numerical comparison.

## 4. Control Flow

**Purpose:** Control flow decides which instructions run, which records are processed, and when repeated calculations stop.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| `if` | Runs code when a condition is true. | Selects records above a threshold. |
| `elif` | Checks another condition if the previous ones were false. | Classifies values into multiple categories. |
| `else` | Runs when no previous condition was true. | Handles remaining observations. |
| Nested `if` | Conditional inside another conditional. | Applies multiple validation rules. |
| Comparison operators | `==`, `!=`, `<`, `>`, `<=`, `>=`. | Filters data using numerical conditions. |
| `and` | True only if both conditions are true. | Filters on multiple criteria. |
| `or` | True if at least one condition is true. | Selects alternative categories. |
| `not` | Reverses a Boolean condition. | Excludes unwanted records. |
| Truthy / Falsy | Values treated as true or false. Falsy: `0`, `0.0`, `""`, `[]`, `{}`, `set()`, `None`, `False`. | Checks whether a collection is empty. |
| `for` | Iterates over an iterable. | Processes observations and features. |
| `while` | Repeats while a condition is true. | Iterates until convergence. |
| Iterable | Object that can provide elements one by one (list, string, dict, file...). | Supplies records to loops. |
| Iterator | Object that produces elements one at a time with `next()`. | Processes data incrementally. |
| `range()` | Generates integers: `range(start, stop, step)` (stop excluded). | Controls training iterations. |
| Nested loop | Loop inside another loop. | Compares pairs of observations. |
| `break` | Exits the nearest enclosing loop. | Stops processing when a condition is met. |
| `continue` | Skips to the next iteration. | Ignores invalid records. |
| `pass` | Placeholder that does nothing. | Marks unfinished processing logic. |
| Loop `else` | Runs when a loop finishes **without** `break`. | Reports an unsuccessful search. |
| Infinite loop | Loop with no natural stopping point (`while True:`). | Continuous monitoring, as long as a `break` exit is provided. |
| Ternary expression | One-line conditional: `a if condition else b`. | Assigns simple labels. |
| `match` / `case` | Pattern-matching control flow (Python 3.10+). | Handles different input formats. |
| Short-circuit evaluation | Stops evaluating as soon as the Boolean result is known. | Avoids unnecessary or unsafe checks. |

### Example: Conditions

```python
score = 72

if score >= 80:
    grade = "A"
elif score >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)                                   # B

label = "pass" if score >= 50 else "fail"      # ternary expression
print(label)                                   # pass

age, has_id = 20, True
if age >= 18 and has_id:
    print("Allowed")                           # Allowed

data = []
if not data:                                   # empty list is falsy
    print("No data")                           # No data
```

### Example: Loops

```python
for i in range(3):
    print(i)                  # 0, 1, 2 (one per line)

# Skip invalid records with continue
readings = [5, -1, 8, None, 12]
valid = []
for value in readings:
    if value is None or value < 0:
        continue
    valid.append(value)
print(valid)                  # [5, 8, 12]

# Loop else: runs only if no break happened
for value in [3, 7, 9]:
    if value > 10:
        print("Found:", value)
        break
else:
    print("No value above 10")   # No value above 10

# while: repeat until a condition is met (like convergence)
value, steps = 100.0, 0
while value > 1:
    value /= 2
    steps += 1
print(steps)                  # 7

# Nested loop: all pairs
for a in [1, 2]:
    for b in ["x", "y"]:
        print(a, b)           # 1 x, 1 y, 2 x, 2 y
```

### Example: Pattern Matching and Short-Circuit

```python
def describe(file_name):
    match file_name.split(".")[-1]:
        case "csv":
            return "CSV file"
        case "json":
            return "JSON file"
        case _:                     # _ matches anything (default case)
            return "Unknown format"

print(describe("data.csv"))         # CSV file
print(describe("image.png"))        # Unknown format

# Short-circuit: data[0] is only checked if data is not empty
data = []
if data and data[0] > 0:
    print("First value is positive")
else:
    print("Empty or not positive")  # Empty or not positive
```

> **Tip:** Use `is None` (not `== None`) to check for missing values.

> **Remember:** `if` decides; `for` iterates; `while` repeats; `break` stops; `continue` skips.

## 5. Functions and Comprehensions

**Purpose:** Functions make calculations reusable; comprehensions transform and filter collections in one short line.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Function | Reusable block of code. | Reuses cleaning and statistical calculations. |
| `def` | Defines a function. | Creates custom analytical functions. |
| Function call | Executes a function: `mean(scores)`. | Runs calculations on data. |
| Parameter | Name in a function **definition**. | Specifies dataset or threshold inputs. |
| Argument | Actual value passed in a function **call**. | Supplies observations or settings. |
| Positional argument | Matched to parameters by position. | Passes required inputs in order. |
| Keyword argument | Passed by parameter name: `scale(5, factor=3)`. | Makes settings explicit. |
| Default parameter | Has a predefined value: `def f(x, factor=2)`. | Sets default thresholds. |
| `return` | Sends a result back to the caller and ends the function. | Returns statistics or predictions. |
| `None` return | Result of a function with no `return` value. | Represents action-only functions (e.g. printing). |
| `*args` | Collects extra positional arguments in a tuple. | Accepts any number of inputs. |
| `**kwargs` | Collects extra keyword arguments in a dictionary. | Accepts flexible configuration. |
| Lambda function | Small anonymous one-expression function. | Performs short transformations (e.g. sort keys). |
| Recursion | A function that calls itself. | Processes nested structures and trees. |
| Base case | Condition that stops recursion. | Prevents endless recursive calls (`RecursionError`). |
| Docstring | Triple-quoted text that documents a function or class. | Explains expected analytical inputs. |
| Type hint | Annotates an expected type: `def f(x: float) -> float`. | Improves readability and static checking (not enforced at runtime). |
| List comprehension | Creates a list: `[x * 2 for x in data]`. | Transforms numerical observations. |
| Set comprehension | Creates a set: `{x for x in data}`. | Extracts unique categories. |
| Dictionary comprehension | Creates a dictionary: `{k: v for k, v in pairs}`. | Builds feature mappings. |
| Generator expression | Produces values lazily, as needed: `(x for x in data)`. | Processes large sequences without using much memory. |
| Comprehension condition | Filters items: `[x for x in data if x > 0]`. | Removes unwanted observations. |
| Nested comprehension | Uses multiple `for` clauses. | Flattens nested data. |

### Example: Functions

```python
def mean(values: list[float]) -> float:
    """Return the average of a list of numbers."""
    return sum(values) / len(values)

print(mean([80, 85, 90]))          # 85.0

def scale(value, factor=2):        # default parameter
    return value * factor

print(scale(5))                    # 10
print(scale(5, factor=3))          # 15  (keyword argument)

def total(*args):                  # args is a tuple
    return sum(args)

print(total(1, 2, 3))              # 6

def show_settings(**kwargs):       # kwargs is a dict
    print(kwargs)

show_settings(lr=0.01, epochs=10)  # {'lr': 0.01, 'epochs': 10}

square = lambda x: x ** 2
print(square(4))                   # 16
print(sorted(["bb", "a", "ccc"], key=lambda s: len(s)))   # ['a', 'bb', 'ccc']

def factorial(n):
    if n <= 1:                     # base case
        return 1
    return n * factorial(n - 1)    # recursive call

print(factorial(5))                # 120

def log(message):
    print(message)                 # no return statement

result = log("Hello")              # Hello
print(result)                      # None
```

> **Important Point:** Never use a mutable object as a default value (`def add(x, items=[])`). The same list is shared between calls. Use `items=None` and create the list inside the function instead.

### Example: Comprehensions

```python
values = [1, 2, 3, 4, 5]

squares = [v ** 2 for v in values]
print(squares)                     # [1, 4, 9, 16, 25]

evens = [v for v in values if v % 2 == 0]
print(evens)                       # [2, 4]

labels = {c.lower() for c in ["A", "b", "a"]}
print(labels)                      # {'a', 'b'}  (set order may vary)

color_ids = {name: i for i, name in enumerate(["red", "green"])}
print(color_ids)                   # {'red': 0, 'green': 1}

total = sum(v ** 2 for v in values)   # generator expression
print(total)                       # 55

matrix = [[1, 2], [3, 4]]
flat = [x for row in matrix for x in row]   # nested comprehension
print(flat)                        # [1, 2, 3, 4]
```

> **Tip:** Read a nested comprehension in the same order as normal nested loops: `for row in matrix` first, then `for x in row`.

> **Remember:** `def` = reusable operation; comprehension = short way to build a collection.

## 6. Classes and Objects

**Purpose:** Classes combine data and behavior to create reusable data processors, models and analytical pipelines.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Class | Blueprint for creating objects. | Defines a custom dataset or model. |
| Object | Individual instance of a class. | Represents a particular model. |
| Instance | Object created from a class: `model = MeanModel("m1")`. | Holds one model's settings. |
| `class` | Keyword that defines a class. | Organizes complex analysis code. |
| `__init__()` | Initializer; runs automatically when an object is created. | Sets model parameters. |
| `self` | Conventional name for the current instance. | Accesses the object's data and methods. |
| Attribute | Data attached to an object or class. | Stores weights and settings. |
| Instance variable | Attribute belonging to one object (`self.name`). | Gives each model its own parameters. |
| Class variable | Attribute stored on the class and shared by all instances. | Holds shared defaults or metadata. |
| Method | Function defined inside a class. | Implements `fit()` or `predict()`. |
| Instance method | Method that receives the instance as its first argument (`self`). | Trains or uses a particular model. |
| `@classmethod` | Method that receives the class as `cls`. | Provides alternative constructors. |
| `@staticmethod` | Method with no automatic `self` or `cls`. | Groups related utility calculations. |
| Inheritance | Defines a class based on another class. | Reuses shared model functionality. |
| Parent class | Class being inherited from (base class). | Defines a common model interface. |
| Child class | Class that inherits from a parent (subclass). | Implements specialized behavior. |
| Method overriding | Redefines an inherited method in the child class. | Customizes a model's `fit()` or `predict()`. |
| `super()` | Accesses the parent class's methods. | Reuses parent initialization. |
| Encapsulation | Keeps related data and methods together; `_name` marks "internal use". | Keeps model state and behavior together. |
| Polymorphism | Different objects support the same interface. | Calls `predict()` on different model types. |
| `__str__()` | Defines a readable string, used by `print()` and `str()`. | Displays model information. |
| `__repr__()` | Defines a developer-oriented string, used by `repr()` and the console. | Supports debugging. |
| `@property` | Lets a method be read like an attribute (no brackets). | Provides calculated model information. |

### Example: A Simple Model Class

```python
class MeanModel:
    """Predicts the mean of the training values."""

    model_type = "baseline"                 # class variable (shared)

    def __init__(self, name):
        self.name = name                    # instance variables
        self.center_ = None

    def fit(self, values):
        if not self.validate(values):
            raise ValueError("values must not be empty")
        self.center_ = sum(values) / len(values)
        return self                         # allows model = MeanModel(...).fit(...)

    def predict(self, n):
        return [self.center_] * n

    @property
    def is_fitted(self):
        return self.center_ is not None

    @classmethod
    def default(cls):                       # alternative constructor
        return cls("default")

    @staticmethod
    def validate(values):                   # utility, no self needed
        return len(values) > 0

    def __str__(self):
        return f"{self.name} (center={self.center_})"

    def __repr__(self):
        return f"{type(self).__name__}(name={self.name!r})"


class MedianModel(MeanModel):               # inheritance
    """Predicts the median of the training values."""

    def __init__(self, name):
        super().__init__(name)              # reuse parent initialization

    def fit(self, values):                  # method overriding
        s = sorted(values)
        mid = len(s) // 2
        self.center_ = s[mid] if len(s) % 2 else (s[mid - 1] + s[mid]) / 2
        return self


mean_model = MeanModel("m1").fit([10, 20, 30])
print(mean_model.predict(2))        # [20.0, 20.0]
print(mean_model.is_fitted)         # True   (property: no brackets)
print(mean_model)                   # m1 (center=20.0)
print(repr(mean_model))             # MeanModel(name='m1')
print(MeanModel.model_type)         # baseline
print(MeanModel.default().name)     # default

median_model = MedianModel("m2").fit([1, 2, 100])

# Polymorphism: same method call, different behavior
for model in [mean_model, median_model]:
    print(repr(model), model.predict(1))
# MeanModel(name='m1') [20.0]
# MedianModel(name='m2') [2]
```

> **Note:** The trailing underscore in `center_` follows the scikit-learn convention for attributes that are learned during `fit()`.

> **Remember:** Class = blueprint; object = instance; attribute = data; method = behavior.

## 7. Collections

**Purpose:** Collections organize observations, labels, feature values and structured records.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Collection | Object containing multiple elements. | Groups observations. |
| List | Ordered, mutable sequence. | Stores measurements. |
| Tuple | Ordered, immutable sequence. | Stores fixed coordinates. |
| Set | Unordered collection of unique elements. | Finds distinct categories. |
| Dictionary | Key-value collection. | Represents records and feature mappings. |
| Element | Individual item in a collection. | Represents one observation. |
| Index | Position in a sequence (starts at `0`; `-1` is the last item). | Accesses an observation. |
| Key | Unique identifier for a dictionary value (must be immutable). | Names a feature. |
| Value | Data associated with a key. | Stores a feature value. |
| `append()` | Adds one item to the end of a list. | Collects results in a loop. |
| `extend()` | Adds all items from an iterable to a list. | Combines data batches. |
| `insert()` | Inserts an item at a given index. | Adds an observation at a position. |
| `remove()` | Removes the first matching list item (`ValueError` if missing). | Deletes an unwanted value. |
| `pop()` | Removes and returns an item (the last one by default). | Retrieves and removes queued data. |
| `sort()` | Sorts a list in place and returns `None`. | Orders measurements. |
| `sorted()` | Returns a new sorted list from any iterable. | Sorts without changing the original. |
| `reverse()` | Reverses a list in place. | Reverses observation order. |
| `add()` | Adds an item to a set. | Collects unique labels. |
| `discard()` | Removes a set item if present (no error if missing). | Excludes an unwanted category. |
| Union `\|` | Combines elements from sets. | Finds all categories across datasets. |
| Intersection `&` | Finds elements shared by sets. | Identifies shared record IDs. |
| Difference `-` | Finds elements in the first set but not the second. | Finds records missing from another dataset. |
| `keys()` | Returns a view of dictionary keys. | Inspects feature names. |
| `values()` | Returns a view of dictionary values. | Extracts feature values. |
| `items()` | Returns a view of `(key, value)` pairs. | Iterates through record fields. |
| `get()` | Retrieves a value, with an optional default if the key is missing. | Handles optional fields without `KeyError`. |
| `update()` | Adds or replaces dictionary entries. | Updates structured records. |
| Membership `in` | Tests whether an item (or dictionary key) exists. | Checks categories and keys. |

### Example: Lists

```python
scores = [70, 85]
scores.append(90)           # [70, 85, 90]
scores.extend([60, 75])     # [70, 85, 90, 60, 75]
scores.insert(0, 100)       # [100, 70, 85, 90, 60, 75]
scores.remove(60)           # [100, 70, 85, 90, 75]
last = scores.pop()         # last = 75, scores = [100, 70, 85, 90]

print(sorted(scores))       # [70, 85, 90, 100]  (scores is unchanged)
scores.sort()               # scores = [70, 85, 90, 100]
scores.reverse()            # scores = [100, 90, 85, 70]
print(85 in scores)         # True
```

> **Important Point:** `scores = scores.sort()` is a common bug. `sort()` returns `None`, so `scores` becomes `None`. Use `scores.sort()` alone, or `scores = sorted(scores)`.

### Example: Sets and Dictionaries

```python
a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)                # {1, 2, 3, 4}
print(a & b)                # {2, 3}
print(a - b)                # {1}
a.add(5)                    # {1, 2, 3, 5}
a.discard(99)               # no error even though 99 is not in the set

record = {"name": "Ali", "age": 25}
print(record.get("city", "Unknown"))        # Unknown
record.update({"age": 26, "city": "Lahore"})
print(list(record.keys()))                  # ['name', 'age', 'city']
print("name" in record)                     # True  (checks keys)

for key, value in record.items():
    print(key, "->", value)
# name -> Ali
# age -> 26
# city -> Lahore
```

> **Remember:** List = changeable; tuple = fixed; set = unique; dictionary = key → value.

## 8. Exceptions

**Purpose:** Exception handling helps programs respond to invalid data, missing files and unexpected failures without crashing.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Exception | Error or unusual event during execution. | Signals processing problems. |
| Exception handling | Code that responds to exceptions. | Makes data pipelines more robust. |
| `try` | Contains code that might fail. | Attempts a data conversion. |
| `except` | Handles a matching exception. | Responds to invalid input. |
| `else` | Runs only when the `try` block raised no exception. | Processes validated values. |
| `finally` | Always runs when leaving the `try` statement, with or without an exception. | Releases resources or logs completion. |
| `raise` | Manually triggers an exception. | Rejects invalid model parameters. |
| `as e` | Binds the caught exception to a name. | Records error details. |
| Custom exception | Programmer-defined exception class (inherits from `Exception`). | Represents domain-specific data errors. |
| `Exception` | Base class for most ordinary exceptions. | Handles unexpected errors at suitable boundaries. |
| `ValueError` | Right type but inappropriate value: `float("abc")`. | Handles invalid numerical input. |
| `TypeError` | Inappropriate type for an operation: `"5" + 5`. | Detects strings passed to numerical functions. |
| `ZeroDivisionError` | Division or modulo by zero. | Handles invalid ratios. |
| `IndexError` | Sequence index out of range. | Detects out-of-range observations. |
| `KeyError` | Missing dictionary key. | Detects absent record fields. |
| `NameError` | Name used before it was defined. | Finds undefined variables. |
| `AttributeError` | Requested attribute or method does not exist. | Finds incorrect object usage. |
| `FileNotFoundError` | Requested file does not exist. | Handles missing datasets. |
| `ImportError` | Module or a name inside it cannot be imported. | Diagnoses import problems. |
| `ModuleNotFoundError` | Requested module cannot be found (subclass of `ImportError`). | Detects missing dependencies (`pip install` needed). |
| `AssertionError` | An `assert` statement evaluates to false. | Checks assumptions during development. |
| Traceback | Report showing where an exception occurred (read it from the bottom up). | Helps debug analysis code. |

### Example: Skip Invalid Values

```python
raw_values = ["10", "20", "unknown", "30"]
clean_values = []

for value in raw_values:
    try:
        clean_values.append(float(value))
    except ValueError:
        print("Skipping invalid value:", value)

print(clean_values)
```

Output:

```text
Skipping invalid value: unknown
[10.0, 20.0, 30.0]
```

### Example: try, except, else and finally

```python
def safe_ratio(a, b):
    try:
        result = a / b
    except ZeroDivisionError as e:
        print("Error:", e)
        return None
    else:
        print("Success")
        return result
    finally:
        print("Done")             # runs even after return

print(safe_ratio(10, 2))
# Success
# Done
# 5.0

print(safe_ratio(1, 0))
# Error: division by zero
# Done
# None
```

### Example: raise and Custom Exceptions

```python
class DataValidationError(Exception):
    """Raised when a value fails a data validation rule."""

def check_age(age):
    if age < 0:
        raise DataValidationError(f"Invalid age: {age}")
    return age

try:
    check_age(-5)
except DataValidationError as e:
    print(e)                      # Invalid age: -5

def set_learning_rate(lr):
    if lr <= 0:
        raise ValueError("Learning rate must be positive")
    return lr

values = [1, 2, 3]
assert len(values) > 0, "values must not be empty"   # passes silently
```

> **Tip:** Catch **specific** exceptions (`except ValueError:`) instead of a bare `except:`. A bare `except` also hides real bugs and even stops `Ctrl + C` from working.

> **Remember:** `try` = attempt; `except` = handle; `else` = success; `finally` = cleanup.

## 9. File Handling

**Purpose:** File handling imports datasets, exports results, and exchanges information between programs.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| File handling | Reads, writes and manages files. | Imports and exports datasets. |
| `open()` | Opens a file and returns a file object. | Accesses raw data on disk. |
| File object | Object used to read from or write to an open file. | Reads and writes dataset contents. |
| `close()` | Closes an open file. | Releases file resources. |
| `with open()` | Context manager that closes the file automatically, even after an error. | Safely handles dataset files. |
| `"r"` | Read mode (default); error if the file does not exist. | Loads existing data. |
| `"w"` | Write mode; creates the file or **overwrites** existing content. | Saves processed results. |
| `"a"` | Append mode; adds to the end of the file. | Adds records or log entries. |
| `"x"` | Exclusive creation mode; error if the file already exists. | Avoids replacing an existing output. |
| `"b"` | Binary mode, combined with another mode (`"rb"`, `"wb"`). | Reads images and other binary data. |
| `"+"` | Adds reading and writing, combined with another mode (`"r+"`). | Supports file updates when appropriate. |
| `read()` | Reads the whole file (or `n` characters) as one string. | Loads a small text dataset. |
| `readline()` | Reads one line. | Processes a single record. |
| `readlines()` | Reads all lines into a list. | Loads a small line-based dataset. |
| `write()` | Writes a string (or bytes in binary mode). | Saves reports and results. |
| `writelines()` | Writes an iterable of strings; does **not** add newlines. | Saves text records. |
| Encoding | Rules for converting text to and from bytes. | Reads multilingual datasets. |
| UTF-8 | Most common Unicode text encoding. | Handles international text (e.g. Urdu, Arabic). |
| `tell()` | Returns the current position in the file. | Tracks file-processing position. |
| `seek()` | Moves to a position in the file: `seek(0)` = beginning. | Returns to the beginning of a file. |
| File path | Location of a file. | Locates training and test datasets. |
| Absolute path | Full path from the filesystem root, e.g. `C:/data/train.csv`. | Accesses files by complete location. |
| Relative path | Path relative to the current working directory, e.g. `data/train.csv`. | Keeps projects portable. |
| `pathlib` | Standard-library module for filesystem paths. | Manages input and output folders. |
| `Path` | Object representing a path; supports `/` to join parts. | Checks existence and reads files. |
| CSV | Comma-separated text format for tabular data. | Stores rows and columns. |
| `csv.reader()` | Reads CSV rows as lists. | Imports tabular data. |
| `csv.DictReader()` | Reads CSV rows as dictionaries keyed by the header row. | Accesses columns by name. |
| `csv.writer()` | Writes CSV rows. | Exports analysis results. |
| JSON | Text format for structured (nested) data. | Stores API responses and settings. |
| `json.dump()` | Writes Python data as JSON to a file. | Saves structured results. |
| `json.load()` | Reads JSON from a file into Python. | Loads records and configuration. |

### Example: Read a CSV File

Suppose `students.csv` contains:

```text
Name,Age
Ali,21
Sara,22
```

```python
import csv

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["Name"], row["Age"])
# Ali 21
# Sara 22
```

> **Note:** CSV values are always read as **strings**. Convert them yourself, for example `int(row["Age"])`. The `newline=""` argument is recommended by the `csv` module so line endings are handled correctly.

### Example: Write a JSON File

```python
import json

results = {"total_students": 100, "average_score": 82.5}

with open("results.json", "w", encoding="utf-8") as file:
    json.dump(results, file, indent=4)
```

### Example: Read a JSON File with pathlib

```python
import json
from pathlib import Path

path = Path("results.json")          # use Path("output") / "results.json" to join folders
if path.exists():
    with path.open("r", encoding="utf-8") as file:
        data = json.load(file)
    print(data["average_score"])     # 82.5
else:
    print("File not found:", path)
```

> **Tip:** For large tables, use pandas instead: `pd.read_csv("students.csv")`. See the [Pandas notes](<7.2(b) pandas.md>).

> **Remember:** `r` = read; `w` = overwrite; `a` = append; `x` = create; `b` = binary.

## 10. Imports and Modules

**Purpose:** Imports let you reuse code from Python's standard library, third-party libraries and your own modules.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Module | A Python file (`.py`) containing reusable code. | Separates cleaning and analysis logic. |
| `import` | Makes a module available. | Loads `math` and `statistics`. |
| `from ... import` | Imports specific names from a module. | Accesses only the needed functions. |
| Alias `as` | Gives an alternative (usually shorter) name. | Uses `numpy as np` and `pandas as pd`. |
| Standard library | Modules that come with Python. | Uses `math`, `csv`, `json` and `statistics`. |
| Third-party module | Module provided by an external package (install with `pip`). | Uses NumPy, pandas and scikit-learn. |
| Custom module | Module written by you. | Reuses project-specific functions. |
| Module namespace | The names defined inside a module (`math.sqrt`). | Avoids naming conflicts. |
| `__name__` | Special variable holding the module's name. | Controls script-specific behavior. |
| `__main__` | Value of `__name__` for the file that is run directly. | Runs analysis only when a script is executed directly. |
| Import path | Locations Python searches for modules. | Finds custom project modules. |
| `sys.path` | List of module search locations. | Diagnoses import problems. |
| Circular import | Two modules importing each other. | Signals a problematic project structure. |
| `dir()` | Lists the names available on an object or module. | Explores unfamiliar libraries. |
| `help()` | Displays documentation. | Learns how analytical functions work. |

### Example: Importing Modules

```python
import math
import statistics

# Third-party packages must be installed first: pip install numpy pandas
import numpy as np
import pandas as pd

scores = [80, 85, 90]
print(statistics.mean(scores))   # 85
print(math.sqrt(25))             # 5.0

array = np.array(scores)
df = pd.DataFrame({"score": scores})
print(array.mean())              # 85.0
print(df["score"].max())         # 90
```

> **Tip:** Avoid `from module import *`. It hides where names come from and can silently overwrite your own variables.

### Example: Your Own Module

File `cleaning.py`:

```python
def remove_missing(values):
    """Return the values without None."""
    return [v for v in values if v is not None]
```

File `main.py` (in the same folder):

```python
from cleaning import remove_missing

print(remove_missing([1, None, 3]))   # [1, 3]
```

> **Important Point:** Do not name your file after a library you use (for example `math.py`, `pandas.py`, `random.py`). Python would import your file instead of the real library.

### Direct Execution Check

```python
def main():
    print("Run the analysis")

if __name__ == "__main__":
    main()
```

- Running `python cleaning.py` directly → `__name__` is `"__main__"`, so `main()` runs.
- Importing it with `import cleaning` → `__name__` is `"cleaning"`, so `main()` does **not** run.

> **Remember:** Module = reusable `.py` file; `import` = use code from another module.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Package | Folder that groups related Python modules. | Groups cleaning and modeling code. |

| Dependency | External package required by a project. | Records the libraries used in an analysis. |
| `pip` | Python package installer. | Installs data science libraries. |
| PyPI | Python Package Index, the online store of Python packages (https://pypi.org). | Provides third-party packages. |

| `requirements.txt` | Common file listing a project's dependencies. | Shares project requirements. |

### Example: Package Structure

```text
my_project/
├── main.py
└── analysis/
    ├── __init__.py
    ├── cleaning.py
    └── models/
        ├── __init__.py
        └── linear.py
```

```python
# In main.py — absolute import
from analysis.cleaning import remove_missing

# In analysis/models/linear.py — relative import (".." = one package up)
from ..cleaning import remove_missing
```

> **Note:** Relative imports only work inside a package. Run the project from the top folder (`python main.py` or `python -m analysis.models.linear`), not by running `linear.py` directly.

### Example: Package Management

```bash
# Install common data science packages

# Install an exact version
python -m pip install pandas==2.2.2

python -m pip install --upgrade pandas

python -m pip list
python -m pip show pandas

python -m pip freeze > requirements.txt

python -m pip install -r requirements.txt
```

> **Tip:** `python -m pip` is safer than plain `pip` because it uses exactly the same Python that runs your code.

## 12. Virtual Environments

**Purpose:** Virtual environments give each project its own Python packages, which avoids dependency conflicts and makes results reproducible.

| Term | Meaning / Purpose | Use in Data Science |
|---|---|---|
| Virtual environment | Isolated Python environment with its own packages. | Gives each project separate dependencies. |
| `venv` | Built-in module for creating virtual environments. | Creates isolated environments. |
| Environment isolation | Keeps project dependencies separate. | Runs projects that need different package versions. |
| Dependency conflict | Two packages need incompatible versions of a third. | Explains environment-specific failures. |
| Interpreter | Program that executes Python code (`python.exe`). | Selects the Python used for an analysis. |
| Activation | Adjusts the shell so `python` and `pip` use the environment. | Directs commands to the intended environment. |
| `deactivate` | Exits an activated environment. | Returns to the previous shell environment. |
| Environment directory | Folder containing the environment files (e.g. `.venv`). | Keeps project dependencies together. |
| `site-packages` | Folder inside the environment where packages are installed. | Stores analytical libraries. |
| Reproducibility | Ability to recreate the same working environment. | Supports collaboration and repeatable experiments. |
| `.gitignore` | Lists files and folders Git should ignore. | Excludes local environments and generated files. |
| `python -m` | Runs a module with the selected interpreter. | Runs `pip` or `venv` with the intended Python. |

### Example: Create and Use an Environment

```bash
# Create an environment in a folder named .venv
python -m venv .venv

# Activate on Windows (Command Prompt)
.venv\Scripts\activate

# Activate on Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Activate on macOS / Linux
source .venv/bin/activate

# Install packages in the active environment
python -m pip install numpy pandas matplotlib

# Save dependency versions
python -m pip freeze > requirements.txt

# Leave the environment
deactivate
```

> **Tip:** After activation, the prompt shows `(.venv)`. Check which Python is active with `python -c "import sys; print(sys.executable)"`.

### venv vs conda

| Feature | `venv` | `conda` |
|---|---|---|
| Comes with Python | Yes | No (install Miniconda / Anaconda) |
| Choose any Python version | No (uses the Python that created it) | Yes: `conda create -n ds python=3.12` |
| Installs non-Python tools | No | Yes (e.g. compilers, CUDA libraries) |
| Activate | `.venv\Scripts\activate` | `conda activate ds` |
| Record dependencies | `pip freeze > requirements.txt` | `conda env export > environment.yml` |

> More details: [Miniconda notes](<4 minicoda.md>) and [Setting Up Environment](<1 setting_up_env.md>)

### Recommended `.gitignore`

```gitignore
.venv/
__pycache__/
*.pyc
.ipynb_checkpoints/
.env
```

> **Important Point:** Never commit the `.venv` folder or `.env` files (they may contain API keys). Commit `requirements.txt` instead, so others can rebuild the environment.
