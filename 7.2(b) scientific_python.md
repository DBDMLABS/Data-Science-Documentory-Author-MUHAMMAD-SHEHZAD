### Inspecting Data
```bash
df.head()

df.describe()                 # count, mean, std, min, 25%, 50%, 75%, max

df["Age"]                     # selecting coulumn

    ["Name", "Age"]
    ]


# Label Based Selection
df.loc[0]                   # loc performs label-based selection.
df.loc[0, "Age"]            # specific row
df.loc[0:2]                 # rows
df.loc[:, "Age"]            # specific coulumn

df.loc[                     # coulumns
    :,
    ["Name", "Age"]
]

df.iloc[0]          # iloc performs integer-position-based selection.
df.iloc[0, :]       # First row
df.iloc[:, 0]       # First column
df.iloc[0:3, 0:2]   # Rows 0–2 and columns 0–1:
```
| Feature | `loc` | `iloc` |
|---|---|---|
| Selection | Labels | Positions |
| `df.loc[0]` | Label `0` | — |
| `df.iloc[0]` | — | First row |
| Columns | Names | Integer positions |
| Main use | Semantic selection | Positional selection |

### Boolean Filtering
```bash
df[df["Age"] > 25]              # single condition
df[                             # multi conditions with and
    (df["Age"] > 25) &
    (df["Salary"] > 50000)
]

df[                            # multi conditions with and
    (df["Age"] > 25) |
    (df["Salary"] > 50000)
]

df[                             # Not
    ~(df["Age"] > 25)
]                               
```
### isin() and between()
```bash
# isin()
df[
    df["City"].isin(
        ["Lahore", "Islamabad"]
    )
]

# Exclude values
df[
    ~df["City"].isin(
        ["Lahore", "Islamabad"]
    )
]

# Between()
df[
    df["Age"].between(20, 30)
]
```

### String Filtering
```bash
df[
    df["Name"].str.startswith("A")
]                               # String Filtering


df[
    df["Name"].str.contains("Ali")
]                               # Contains

df["Name"].str.lower()          # lowecase

df["Name"].str.upper()          # uppercase

df["Name"].str.strip()          # strip white spaces
```
### Operations on Columns
```bash
# Renaming Columns
df = df.rename(
    columns={
        "Salary": "AnnualSalary"
    }
)

# Rename multiple
df.rename(
    columns={
        "Name": "name",
        "Age": "age"
    }
)

# Changing Column Names
df.columns = [
    "name",
    "age",
    "salary"
]

# Adding Columns
df["Bonus"] = df["Salary"] * 0.10 # Bonus = 10% of Salary

# Creating Columns with Multiple Conditions
df["Status"] = np.where(
    df["Age"] >= 18,
    "Adult",
    "Minor"
)

# For multiple conditions
df["Grade"] = np.select(
    [
        df["Score"] >= 80,
        df["Score"] >= 60,
        df["Score"] < 60
    ],
    [
        "A",
        "B",
        "C"
    ]
)
