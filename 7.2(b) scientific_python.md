### Creating Series
```bash
s = pd.Series([10, 20, 30, 40]) # A Series is a one-dimensional labeled array.

# With custom indx
s = pd.Series(
    [10, 20, 30],
    index=["a", "b", "c"]
)

# From Dictionary
s = pd.Series({
    "Math": 90,
    "Physics": 85,
    "Python": 95
})
```

### Inspecting Data
```bash
df.head()
df.head(10)
df.tail()
df.info()                  # Number of rows, Columns, Non-null counts, Data types, Memory usage
df.describe()                 # count, mean, std, min, 25%, 50%, 75%, max
df.describe(include="object") # for catagorical data
df.describe(include="all")    # for All coulumns
df.dtypes                     # Checking data type
df["Age"]                     # selecting coulumn

df[                           # selecting multiple coulumn
    ["Name", "Age"]
    ]


# Label Based Selection
df.loc[0]                   # loc performs label-based selection.
df.loc[0, "Age"]            # specific row
df.loc[0:2]                 # rows
df.loc[:, "Age"]            # specific coulumn

df.loc[                     # coulumns
    :,
    ["Name", "Age"]
]

df.iloc[0]          # iloc performs integer-position-based selection.
df.iloc[0, :]       # First row
df.iloc[:, 0]       # First column
df.iloc[0:3, 0:2]   # Rows 0–2 and columns 0–1:
```
| Feature | `loc` | `iloc` |
|---|---|---|
| Selection | Labels | Positions |
| `df.loc[0]` | Label `0` | — |
| `df.iloc[0]` | — | First row |
| Columns | Names | Integer positions |
| Main use | Semantic selection | Positional selection |
