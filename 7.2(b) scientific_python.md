### Inspecting Data

### Label Based Selection

```bash
df.loc[0]                         # Select row by label
df.loc[0, "Age"]                  # Select specific value
df.loc[0:2]                       # Select rows by labels
df.loc[:, "Age"]                  # Select column by label

df.loc[
    :,
    ["Name", "Age"]
]                                 # Select multiple columns

df.iloc[0]                        # Select first row by position
df.iloc[0, :]                     # First row
df.iloc[:, 0]                     # First column
df.iloc[0:3, 0:2]                 # Rows 0–2, columns 0–1
```

| Feature | `loc` | `iloc` |
|---|---|---|
| Selection | Labels | Positions |
| Columns | Names | Integer positions |
| Main use | Semantic selection | Positional selection |

### Boolean Filtering

```bash
df[df["Age"] > 25]                # Single condition

df[
    (df["Age"] > 25) &
    (df["Salary"] > 50000)
]                                 # AND condition

df[
    (df["Age"] > 25) |
    (df["Salary"] > 50000)
]                                 # OR condition

df[
    ~(df["Age"] > 25)
]                                 # NOT condition
```

### isin() and between()

```bash

```

### Operations on Columns

```bash
df["Grade"] = np.select(
```

```bash

    axis=1
)                                 # Remove columns containing missing values

    how="all"
```

### Filling Missing Values

```bash
df.fillna(0)                      # Fill with constant

df["Age"] = df["Age"].fillna(
    df["Age"].mean()
)                                 # Fill with mean

df["Age"] = df["Age"].fillna(
    df["Age"].median()
)                                 # Fill with median

df.ffill()                        # Forward fill
df.bfill()                        # Backward fill
```

```text
Detect
   ↓
Understand why missing
   ↓
Determine missingness pattern
   ↓
Drop / Impute / Flag
   ↓
Validate
```

### Rolling & Expanding & Exponentially Weighted Windows

```bash
df["RollingMean"] = (
    df["Sales"]
    .rolling(7)
    .mean()
)                                 # 7-period moving average

.rolling(7).sum()                 # Rolling sum
.rolling(7).std()                 # Rolling standard deviation
.rolling(7).min()                 # Rolling minimum
.rolling(7).max()                 # Rolling maximum
```

```bash
df["CumulativeMean"] = (
    df["Sales"]
    .expanding()
    .mean()
)                                 # Cumulative mean
```

```bash
df["EMA"] = (
    df["Sales"]
    .ewm(span=7)
    .mean()
)                                 # Exponentially weighted mean
```

### Types of Joins

| Join | Meaning |
|---|---|
| `inner` | Matching rows only |
| `left` | All left + matching right |
| `right` | All right + matching left |
| `outer` | All rows from both |

```bash
pd.merge(
    df1,
    df2,
    on="ID",
    how="left"
)                                  # Left join
```

### Merge on Different Column Names

```bash
pd.merge(
    df1,
    df2,
    left_on="CustomerID",
    right_on="ID"
)                                  # Different key names
```

### join on index

```bash
df1.join(
    df2,
    how="left"
)                                  # Index-based join

df1.join(
    df2.set_index("ID"),
    on="ID"
)                                  # Join using column and index
```

### Concatenation

```bash
pd.concat(
    [df1, df2],
    axis=0
)                                  # Stack rows

pd.concat(
    [df1, df2],
    axis=1
)                                  # Stack columns

pd.concat(
    [df1, df2],
    ignore_index=True
)                                  # Combine and reset index
```

| Operation | Best For |
|---|---|
| `merge()` | Relational/database-style joins |
| `concat()` | Stacking datasets |
| `join()` | Index-based joining |

### Wide vs Long Data

```text
# Wide

Name    Math    Physics    Chemistry
Ali      90       80          85


# Long

Name    Subject      Score
Ali     Math           90
Ali     Physics        80
Ali     Chemistry      85
```

```bash
melt()                             # Wide → Long
pivot()                            # Long → Wide
pivot_table()                      # Long → summarized wide
```
