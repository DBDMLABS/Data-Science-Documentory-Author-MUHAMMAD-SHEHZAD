## What is Pandas?

**Pandas** is a Python library built around powerful data structures for working with **structured (tabular) and labeled data**, like spreadsheets and SQL tables. It is built on top of NumPy (see the [NumPy notes](<7.2(a) scientific_python_numpy.md>)).

The most important objects in Pandas are:

| Object | What it is | Example |
|---|---|---|
| **Series** | A one-dimensional labeled array (a single column) | A list of ages |
| **DataFrame** | A two-dimensional table of rows and columns (many Series sharing one index) | An employee table |
| **Index** | The labels for the rows (and columns) of a Series or DataFrame | `0, 1, 2, ...` or names, dates |

> **Note:** The examples in these notes use **Pandas 2.x / 3.x**. Some older code you find online (for example `df.append()`) no longer works — the modern replacement is shown where it matters.

## Series

### Creating Series

A **Series** is a one-dimensional labeled array. Every value has a label (its **index**).

```python
# From a list (default index 0, 1, 2, ...)
s = pd.Series([10, 20, 30, 40])

# With a custom index
s = pd.Series(
    [10, 20, 30],
    index=["a", "b", "c"]
)

# From a dictionary (keys become the index)
s = pd.Series({
    "Math": 90,
    "Physics": 85,
    "Python": 95
})
print(s)
```

```text
# Output:
Math       90
Physics    85
Python     95
dtype: int64
```

### Series Attributes

| Attribute | Returns | Example result (for `s` above) |
|---|---|---|
| `s.index` | The labels | `Index(['Math', 'Physics', 'Python'], ...)` |
| `s.values` | The values as a NumPy array | `array([90, 85, 95])` |
| `s.dtype` | The data type of the values | `int64` |
| `s.shape` | Shape as a tuple | `(3,)` |
| `s.size` | Number of elements | `3` |
| `s.ndim` | Number of dimensions | `1` |

```python
s.index
s.values
s.dtype
s.shape
s.size
s.ndim
```

> **Tip:** `s.to_numpy()` is the modern, recommended way to get a NumPy array; `s.values` still works.

## DataFrames

### Creating DataFrames

A **DataFrame** is a table: rows have an index, and each column is a Series.

```python
# From a dictionary (keys become column names)
df = pd.DataFrame({
    "Name": ["Ali", "Sara"],
    "Age": [25, 30]
})

# From a list of dictionaries (each dictionary is one row)
df = pd.DataFrame([
    {"Name": "Ali", "Age": 25},
    {"Name": "Sara", "Age": 30}
])

# From a NumPy array
import numpy as np
data = np.array([[1, 2], [3, 4]])
df = pd.DataFrame(data, columns=["A", "B"])
```

The sample DataFrame used in many examples below:

```python
df = pd.DataFrame({
    "Name": ["Ali", "Sara", "Ahmed"],
    "Age": [25, 30, 28],
    "Salary": [50000, 70000, 60000]
})
print(df)
```

```text
# Output:
    Name  Age  Salary
0    Ali   25   50000
1   Sara   30   70000
2  Ahmed   28   60000
```

### DataFrame Attributes

| Attribute | Returns | Result for the sample `df` |
|---|---|---|
| `df.shape` | `(rows, columns)` | `(3, 3)` |
| `df.size` | Total number of cells (rows × columns) | `9` |
| `df.ndim` | Number of dimensions | `2` |
| `df.columns` | Column labels | `Index(['Name', 'Age', 'Salary'], ...)` |
| `df.index` | Row labels | `RangeIndex(start=0, stop=3, step=1)` |
| `df.dtypes` | Data type of each column | `Name: str/object, Age: int64, Salary: int64` |
| `df.values` | All data as a NumPy array | 2-D array |

```python
df.shape
df.size
df.ndim
df.columns
df.index
df.dtypes
df.values
```

> **Note:** Text columns show as `object` in Pandas 2.x and as `str` in Pandas 3.x.

## Reading and Writing Data

### Reading CSV, Excel, JSON and SQL Files

| Function | Reads |
|---|---|
| `pd.read_csv()` | CSV / text files |
| `pd.read_excel()` | Excel files (`.xlsx`, `.xls`) — needs `openpyxl` |
| `pd.read_json()` | JSON files |
| `pd.read_sql()` | Results of a SQL query from a database |

```python
df = pd.read_csv("data.csv")        # CSV

df = pd.read_excel("data.xlsx")     # Excel (first sheet)

# A specific sheet in an Excel file
df = pd.read_excel(
    "data.xlsx",
    sheet_name="Sales"
)

df = pd.read_json("data.json")      # JSON
```

Reading from SQL needs a database **connection** object:

```python
import sqlite3

connection = sqlite3.connect("shop.db")   # Connect to a SQLite database

df = pd.read_sql(
    "SELECT * FROM customers",
    connection
)
```

> **Note:** For Excel files install `openpyxl` first: `pip install openpyxl`.

### Writing Data

```python
# CSV
df.to_csv("output.csv", index=False)

# Excel
df.to_excel("output.xlsx", index=False)

# JSON
df.to_json("output.json")
```

> **Tip:** Use `index=False` so the row numbers `0, 1, 2, ...` are not saved as an extra column.

## Inspecting Data

Always look at your data before working with it.

```python
df.head()                         # First 5 rows
df.head(10)                       # First 10 rows
df.tail()                         # Last 5 rows
df.info()                         # Rows, columns, non-null counts, dtypes, memory
df.describe()                     # Numeric summary: count, mean, std, min, quartiles, max
df.describe(include=["object", "string"])  # Text (categorical) summary: count, unique, top, freq
df.describe(include="all")        # Summary of all columns
df.dtypes                         # Column data types
df["Age"]                         # Select one column (returns a Series)
df[["Name", "Age"]]               # Select multiple columns (returns a DataFrame)
```

> **Note:** In Pandas 2.x `df.describe(include="object")` selects text columns. In Pandas 3.x text columns use the new `str` dtype, so `include=["object", "string"]` (or `include="str"` in 3.x) is the safer choice.

> **Tip:** `df["Age"]` (single brackets) gives a **Series**; `df[["Age"]]` (double brackets) gives a **DataFrame**.

## Index

### Index Concepts

The **index** holds the row labels. It makes selecting, aligning and joining data fast.

```python
df.index                          # Access the row index
```

| Index type | When you see it |
|---|---|
| `RangeIndex` | Default index `0, 1, 2, ...` |
| `DatetimeIndex` | Index made of dates/times (time series) |
| `CategoricalIndex` | Index made of categories |
| `MultiIndex` | Index with more than one level (for example Region → Product) |

### Setting an Index

```python
df = df.set_index("Name")         # Use the "Name" column as the index
df = df.reset_index()             # Move the index back into a normal column
```

### Resetting Index

After filtering or sorting, the index can have gaps (for example `0, 2, 5`). Reset it:

```python
df = df.reset_index(drop=True)    # Create a clean 0, 1, 2, ... index
                                  # drop=True throws the old index away
```

> **Important Point:** Most Pandas methods **return a new object** and do not change `df`. Save the result (`df = df.set_index(...)`) to keep the change.

## Selecting and Filtering Data

### Label and Position Based Selection (loc and iloc)

```python
# loc — select by LABEL
df.loc[0]                         # Row with label 0
df.loc[0, "Age"]                  # Single value
df.loc[0:2]                       # Rows with labels 0 to 2 (2 is INCLUDED)
df.loc[:, "Age"]                  # One column by name
df.loc[:, ["Name", "Age"]]        # Multiple columns by name

# iloc — select by POSITION
df.iloc[0]                        # First row
df.iloc[0, :]                     # First row (all columns)
df.iloc[:, 0]                     # First column
df.iloc[0:3, 0:2]                 # Rows 0–2, columns 0–1 (end is EXCLUDED)
```

| Feature | `loc` | `iloc` |
|---|---|---|
| Selection | Labels | Positions |
| Columns | Names | Integer positions |
| Slice end | **Included** (`0:2` → 0, 1, 2) | **Excluded** (`0:2` → 0, 1) |
| Main use | Semantic (label) selection | Positional selection |

> **Note:** `df.loc[0]` works only when `0` is a label in the index. After `set_index("Name")` you would use `df.loc["Ali"]` instead.

### Boolean Filtering

A condition creates a True/False Series; using it inside `df[...]` keeps only the `True` rows.

```python
df[df["Age"] > 25]                # Single condition

df[
    (df["Age"] > 25) &
    (df["Salary"] > 50000)
]                                 # AND condition

df[
    (df["Age"] > 25) |
    (df["Salary"] > 50000)
]                                 # OR condition

df[~(df["Age"] > 25)]             # NOT condition
```

| Operator | Meaning |
|---|---|
| `&` | AND |
| `\|` | OR |
| `~` | NOT |

> **Important Point:** Use `&`, `|`, `~` (not `and`, `or`, `not`), and put **each condition in parentheses**.

### isin() and between()

The examples below assume the DataFrame also has a `City` column.

```python
df[
    df["City"].isin(["Lahore", "Islamabad"])
]                                 # Keep rows with the selected values

df[
    ~df["City"].isin(["Lahore", "Islamabad"])
]                                 # Exclude the selected values

df[
    df["Age"].between(20, 30)
]                                 # Values from 20 to 30 (both ends included)
```

### String Filtering

Text methods are available through the `.str` accessor.

```python
df[df["Name"].str.startswith("A")]             # Names that start with "A"

df[df["Name"].str.contains("Ali", na=False)]   # Names that contain "Ali"

df["Name"].str.lower()            # Convert to lowercase
df["Name"].str.upper()            # Convert to uppercase
df["Name"].str.strip()            # Remove surrounding spaces
```

> **Tip:** `na=False` treats missing names as "no match", so filtering does not fail when the column has missing values.

## Modifying Columns and Rows

### Operations on Columns

```python
df = df.rename(
    columns={"Salary": "AnnualSalary"}
)                                 # Rename one column

df = df.rename(
    columns={
        "Name": "name",
        "Age": "age"
    }
)                                 # Rename multiple columns

df.columns = [
    "name",
    "age",
    "salary"
]                                 # Replace ALL column names (list length must match)
```

Creating new columns (these use the original column names `Salary`, `Age`, `Score`):

```python
df["Bonus"] = df["Salary"] * 0.10 # Create a calculated column

df["Status"] = np.where(
    df["Age"] >= 18,
    "Adult",
    "Minor"
)                                 # Column from one condition: where(condition, if_true, if_false)

df["Grade"] = np.select(
    [
        df["Score"] >= 80,
        df["Score"] >= 60
    ],
    [
        "A",
        "B"
    ],
    default="C"
)                                 # Multiple conditions — the first True condition wins
```

> **Important Point:** Always give `np.select()` a `default` of the same type as the choices (here `"C"`). Without it, NumPy uses `0` as the default, and newer NumPy versions raise an error when the choices are text.

### assign()

`assign()` returns a new DataFrame with extra columns — useful in method chains.

```python
df = df.assign(
    Bonus=df["Salary"] * 0.1
)                                 # Add a calculated column

df = df.assign(
    Bonus=df["Salary"] * 0.1,
    Total=df["Salary"] * 1.1
)                                 # Add multiple columns
```

### map()

`map()` changes each value using a dictionary (or a function).

```python
mapping = {
    "M": "Male",
    "F": "Female"
}
df["Gender"] = df["Gender"].map(mapping)  # Map values using a dictionary
```

> **Note:** With `map()`, any value **not** in the dictionary becomes `NaN`. Use `replace()` if you want to keep unmatched values.

### replace()

```python
df["Gender"] = df["Gender"].replace({
    "M": "Male",
    "F": "Female"
})  # Replace only the selected values; others stay the same
```

| Method | Unmatched values |
|---|---|
| `map()` | Become `NaN` |
| `replace()` | Stay unchanged |

### Removing Rows and Columns

```python
df = df.drop(columns=["Bonus"])            # Remove one column

df = df.drop(columns=["Bonus", "Status"])  # Remove multiple columns

df = df.drop(index=0)                      # Remove one row (by label)
df = df.drop(index=[0, 1])                 # Remove multiple rows
```

## Sorting

### Sorting Ascending and Descending

The examples below assume the DataFrame also has a `Department` column.

```python
df.sort_values("Salary")          # Ascending (smallest first)

df.sort_values(
    "Salary",
    ascending=False
)                                 # Descending (largest first)

df.sort_values(
    ["Department", "Salary"],
    ascending=[True, False]
)                                 # Department A→Z, then Salary high→low inside each department
```

### Sorting by Index

```python
df.sort_index()                   # Ascending index

df.sort_index(ascending=False)    # Descending index
```

### Selecting Rows with nlargest() and nsmallest()

```python
df.nlargest(10, "Salary")         # Top 10 salaries
df.nsmallest(10, "Salary")        # Bottom 10 salaries
```

> **Tip:** `df.nlargest(10, "Salary")` is a faster, shorter version of `df.sort_values("Salary", ascending=False).head(10)`.

## Cleaning Data

### Missing Data

Missing values are shown as `NaN`, `None`, `NaT` (dates) or `<NA>`.

```python
df.isna()                         # True where a value is missing
df.isna().sum()                   # Count missing values per column
df.isna().mean() * 100            # Percentage of missing values per column
# isnull() and isna() are the same; notnull() and notna() are the same
```

```python
# Universal check (works on DataFrames, Series and single values)
pd.isna(df)                       # Detect missing values
pd.notna(df)                      # Detect available (non-missing) values
df["Salary"].isna().sum()         # Count missing salary values
```

### Dropping Missing Values

```python
df.dropna()                       # Remove rows that contain ANY missing value
df.dropna(axis=1)                 # Remove columns that contain any missing value
df.dropna(how="all")              # Remove rows where ALL values are missing
df.dropna(subset=["Salary"])      # Remove rows where "Salary" is missing
```

### Filling Missing Values

```python
df.fillna(0)                      # Fill with a constant

df["Age"] = df["Age"].fillna(
    df["Age"].mean()
)                                 # Fill with the mean

df["Age"] = df["Age"].fillna(
    df["Age"].median()
)                                 # Fill with the median (better when there are outliers)

df.ffill()                        # Forward fill: copy the previous valid value down
df.bfill()                        # Backward fill: copy the next valid value up
```

> **Note:** `df.fillna(method="ffill")` is deprecated. Use `df.ffill()` and `df.bfill()` instead.

A good workflow for handling missing data:

```text
Detect
   ↓
Understand why it is missing
   ↓
Determine the missingness pattern
   ↓
Drop / Impute / Flag
   ↓
Validate
```

### Duplicates

```python
df.duplicated()                   # True for rows that repeat an earlier row
df.duplicated().sum()             # Count duplicate rows
df.drop_duplicates()              # Remove duplicate rows (keeps the first one)
df.drop_duplicates(
    subset=["Name", "Email"]
)                                 # Treat rows as duplicates using selected columns only
```

## Data Types

### Data Type Conversion

```python
df["Age"] = df["Age"].astype(int)       # Convert to integer (column must have NO missing values)
df["Age"] = df["Age"].astype("Int64")   # Nullable integer — allows missing values (<NA>)

df["Salary"] = pd.to_numeric(
    df["Salary"],
    errors="coerce"
)                                       # Convert to numbers; invalid values → NaN
```

Example of `errors="coerce"`:

```python
s = pd.Series(["100", "200", "abc"])
pd.to_numeric(s, errors="coerce")       # Invalid values become NaN
```

```text
# Output:
0    100.0
1    200.0
2      NaN
dtype: float64
```

> **Important Point:** `astype(int)` raises an error if the column contains `NaN`. Fill or drop missing values first, or use the nullable `"Int64"` type (capital **I**).

### Categorical Data

Use the `category` dtype for columns with a small number of repeated values (departments, cities, grades).

```python
df["Department"] = df["Department"].astype("category")   # Convert to categorical dtype
```

Benefits:
- Lower memory usage
- Faster operations for suitable workloads (grouping, sorting)
- Clear categorical meaning (only fixed values are allowed)

### Categorical Ordering

```python
from pandas.api.types import CategoricalDtype

dtype = CategoricalDtype(
    categories=["Low", "Medium", "High"],
    ordered=True
)
df["Priority"] = df["Priority"].astype(dtype)  # Set the category order

df.sort_values("Priority")              # Sorting follows: Low < Medium < High
df[df["Priority"] > "Low"]              # Comparisons also work: Medium and High
```

### String Data Type

```python
df["Name"] = df["Name"].astype("string")   # Use the Pandas string dtype
```

> **Note:** The `"string"` dtype stores missing text as `<NA>` and makes text columns clearer than the generic `object` dtype. In Pandas 3.x text columns use a string dtype (`str`) by default.

## Working with Text

### String Operations

| Method | Purpose |
|---|---|
| `.str.lower()` / `.str.upper()` | Change case |
| `.str.len()` | Length of each string |
| `.str.strip()` | Remove spaces at the start and end |
| `.str.contains()` | True if the text is found |
| `.str.replace()` | Replace text |
| `.str.split()` | Split into lists |
| `.str.extract()` | Extract a regex pattern into a new column |

```python
df["Name"].str.lower()                     # Lowercase
df["Name"].str.upper()                     # Uppercase
df["Name"].str.len()                       # String length
df["Name"].str.strip()                     # Remove surrounding spaces
df["Name"].str.contains("Ali")             # Find matching text
df["Name"].str.replace("A", "B")           # Replace text
df["Name"].str.split(" ")                  # Split into lists
df["Email"].str.extract(r"@(.+)")          # Extract the domain after "@"
```

Example of `str.extract()`:

```python
emails = pd.Series(["ali@gmail.com", "sara@yahoo.com"])
emails.str.extract(r"@(.+)")
```

```text
# Output:
           0
0  gmail.com
1  yahoo.com
```

### Regular Expressions

```python
df["Email"].str.contains(
    r"@gmail\.com",
    regex=True
)  # True for Gmail addresses
```

> **Tip:** Write patterns as raw strings (`r"..."`) and escape the dot (`\.`), because `.` alone means "any character" in a regex.

## Date and Time

### Converting to Datetime

```python
df["Date"] = pd.to_datetime(df["Date"])    # Convert text to datetime

df["Year"] = df["Date"].dt.year
df["Month"] = df["Date"].dt.month
df["Day"] = df["Date"].dt.day
df["DayName"] = df["Date"].dt.day_name()
```

### Datetime Attributes (.dt)

## Window and Time-Series Functions

### Rolling, Expanding and Exponentially Weighted Windows

**Rolling** — a moving window of fixed size:

```python
df["RollingMean"] = (
    df["Sales"]
    .rolling(7)
    .mean()
)                                 # 7-period moving average

df["Sales"].rolling(7).sum()      # Rolling sum
df["Sales"].rolling(7).std()      # Rolling standard deviation
df["Sales"].rolling(7).min()      # Rolling minimum
df["Sales"].rolling(7).max()      # Rolling maximum
```

> **Note:** The first 6 values of a 7-period rolling result are `NaN`, because there are not yet 7 values. Use `rolling(7, min_periods=1)` to get a value from the first row.

**Expanding** — the window grows from the first row to the current row:

```python
df["CumulativeMean"] = (
    df["Sales"]
    .expanding()
    .mean()
)                                 # Cumulative (running) mean
```

**Exponentially weighted** — recent values get more weight:

```python
df["EMA"] = (
    df["Sales"]
    .ewm(span=7)
    .mean()
)                                 # Exponential moving average
```

| Window | Uses |
|---|---|
| `rolling(n)` | Last `n` rows only |
| `expanding()` | All rows up to now |
| `ewm(span=n)` | All rows, with more weight on recent ones |

## Grouping and Aggregation

`groupby()` follows the **split → apply → combine** idea: split rows into groups, calculate something for each group, and combine the results into one table.

### groupby()

```python
df.groupby("Department")["Salary"].mean()               # Average salary per department
df.groupby(["Department", "Gender"])["Salary"].mean()   # Group by multiple columns
df.groupby("Department")["Salary"].agg(
    ["mean", "median", "min", "max"]
)                                                       # Multiple summary statistics
```

Small example:

```python
staff = pd.DataFrame({
    "Department": ["IT", "IT", "HR", "HR"],
    "Salary": [60000, 80000, 40000, 50000]
})
staff.groupby("Department")["Salary"].mean()
```

```text
# Output:
Department
HR    45000.0
IT    70000.0
Name: Salary, dtype: float64
```

### Named Aggregations

Named aggregations let you choose the name of each result column: `NewName=("column", "function")`.

```python
summary = df.groupby("Department").agg(
    AverageSalary=("Salary", "mean"),  # Average salary
    MaxSalary=("Salary", "max"),       # Highest salary
    Employees=("Salary", "size")       # Number of rows
)
```

### Multiple Aggregations

```python

    "Salary": ["mean", "max"],  # Salary statistics

})
```

### nunique()

```python

df.groupby("City")["CustomerID"].nunique()  # Distinct customers per city
```

### size() vs count()

```python

df.groupby("Department")["Salary"].count()  # Count non-missing salaries in each group
```

| Method | Counts missing values? |
|---|---|
| `size()` | Yes — counts every row |
| `count()` | No — excludes missing values |


### transform()

`transform()` returns a result with the **same length as the original DataFrame**, so it can be saved as a new column.

```python

    df.groupby("Department")["Salary"].transform("mean")

```


### apply()

`apply()` runs your own function on each group.

```python
def salary_range(group):
    return group["Salary"].max() - group["Salary"].min()

df.groupby("Department").apply(salary_range)  # Apply a custom function to each group
```

Prefer the specialized methods when possible — they are faster and clearer:

| Method | Use it to |
|---|---|
| `agg()` | Summarize groups (one row per group) |
| `transform()` | Return row-aligned results (same length as `df`) |
| `filter()` | Keep or remove whole groups |

> **Note:** In Pandas 3.x, `groupby().apply()` no longer passes the grouping column(s) to your function. In Pandas 2.2 you can pass `include_groups=False` to get the same behavior and avoid a warning.

## Combining DataFrames

### Merge

`merge()` joins two DataFrames using a common **key** column, like a SQL `JOIN`.

```python
df = pd.merge(
    customers,
    orders,
    on="CustomerID"
)  # Merge using a common key (inner join by default)
```

### Types of Joins

| Join | Purpose |
|---|---|
| `inner` | Matching rows only (default) |
| `left` | All left rows and matching right rows |
| `right` | All right rows and matching left rows |
| `outer` | All rows from both DataFrames |

```python
pd.merge(
    df1,
    df2,
    on="ID",
    how="left"
)  # Left join
```

Small example:

```python
df1 = pd.DataFrame({"ID": [1, 2, 3], "Name": ["Ali", "Sara", "Ahmed"]})
df2 = pd.DataFrame({"ID": [1, 3], "City": ["Lahore", "Karachi"]})

pd.merge(df1, df2, on="ID", how="left")
```

```text
# Output:
   ID   Name     City
0   1    Ali   Lahore
1   2   Sara      NaN
2   3  Ahmed  Karachi
```

### Merge on Different Column Names

```python
pd.merge(
    df1,
    df2,
    left_on="CustomerID",
    right_on="ID"
)  # Merge when the key has a different name in each DataFrame
```

### Join on Index

```python
df1.join(df2, how="left")  # Join using the indexes of both DataFrames

df1.join(
    df2.set_index("ID"),
    on="ID"
)                          # Join a column of df1 to the index of df2
```

### Concatenation

```python
pd.concat([df1, df2], axis=0)  # Stack rows (one under the other)
pd.concat([df1, df2], axis=1)  # Stack columns (side by side)
pd.concat(
    [df1, df2],
    ignore_index=True
)                              # Combine rows with a new 0, 1, 2, ... index
```

| Operation | Purpose |
|---|---|
| `merge()` | Join using matching keys |
| `concat()` | Stack DataFrames |
| `join()` | Join primarily using indexes |

> **Important Point:** `df.append()` was **removed in Pandas 2.0**. To add rows, use `pd.concat()`:
> ```python
> new_row = pd.DataFrame([{"Name": "Hina", "Age": 27}])
> df = pd.concat([df, new_row], ignore_index=True)
> ```

### pd.NA vs np.nan

|---|---|

### query()

```python
df.query("Age > 25 and Salary > 50000")  # Filter with readable syntax

# Equivalent Boolean filtering:

    (df["Age"] > 25) &
    (df["Salary"] > 50000)
```

```python

```

### eval()

```python
df = df.eval("Total = Price * Quantity")  # Calculate a new column from an expression
```

> **Note:** `eval()` returns a **new** DataFrame; without `df = ...` (or `inplace=True`) the new column is lost.

### Method Chaining

Write several steps as one readable pipeline:

```python
result = (
    df
    .dropna()                                    # Remove rows with missing values
    .query("Age > 25")                           # Filter rows
    .assign(Bonus=lambda x: x["Salary"] * 0.1)   # Add a column
    .sort_values("Salary", ascending=False)      # Sort the result
)
```

### pipe()

`pipe()` lets you use your own functions inside a method chain.

```python
def clean_data(df):
    return df.dropna()            # Define a reusable cleaning step

result = df.pipe(clean_data)      # Same as clean_data(df)
```

### Copy vs View

```python
subset = df[df["Age"] > 25]          # Select matching rows
subset = df[df["Age"] > 25].copy()   # Create an independent copy
```

> **Tip:** Use `.copy()` when you plan to change `subset`, so it is clear that `df` stays unchanged and no `SettingWithCopyWarning` appears. From Pandas 3.0 (Copy-on-Write), changing a subset never changes the original DataFrame.

### Avoid Chained Assignment

```python
# Avoid — this does NOT update df:
df[df["Age"] > 25]["Salary"] = 0

# Prefer — one .loc step:
df.loc[df["Age"] > 25, "Salary"] = 0  # Update the selected rows safely
```

> **Important Point:** Chained assignment (`df[...][...] = value`) first creates a temporary copy and then changes that copy. In older Pandas it gives a `SettingWithCopyWarning`; in Pandas 3.0 it **never** works. Always use `.loc[rows, column] = value`.
