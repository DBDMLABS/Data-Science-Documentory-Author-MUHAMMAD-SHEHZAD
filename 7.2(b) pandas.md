### Types of Joins
\| Join | Purpose |

\|---|---|

\| `inner` | Matching rows only |

\| `left` | All left rows and matching right rows |

\| `right` | All right rows and matching left rows |

\| `outer` | All rows from both DataFrames |

```bash
pd.merge(
    df1,
    df2,
    on="ID",
    how="left"
)  # Left join
```
### Merge on Different Column Names
```bash
pd.merge(
    df1,
    df2,
    left_on="CustomerID",
    right_on="ID"
)  # Merge using different key names
```
### Join on Index
```bash
df1.join(df2, how="left")  # Join using indexes

df1.join(
    df2.set_index("ID"),
    on="ID"
)                            # Join column to index
```
### Concatenation
```bash
pd.concat([df1, df2], axis=0)  # Stack rows
pd.concat([df1, df2], axis=1)  # Stack columns
pd.concat(
    [df1, df2],
    ignore_index=True
)                       # Combine rows with a new index
```

\| Operation | Purpose |

\|---|---|

\| `merge()` | Join using matching keys |

\| `concat()` | Stack DataFrames |

\| `join()` | Join primarily using indexes |

### Detecting Outliers with IQR
```bash
df["Salary"].quantile(0.5)  # Calculate median

df["Salary"].quantile(
    [0.25, 0.5, 0.75]
)  # Calculate quartiles

Q1 = df["Salary"].quantile(0.25)  # First quartile
Q3 = df["Salary"].quantile(0.75)  # Third quartile
IQR = Q3 - Q1  # Interquartile range
lower = Q1 - 1.5 * IQR  # Lower boundary
upper = Q3 + 1.5 * IQR  # Upper boundary

outliers = df[
    (df["Salary"] < lower) |
    (df["Salary"] > upper)
]  # Select potential outliers
```
