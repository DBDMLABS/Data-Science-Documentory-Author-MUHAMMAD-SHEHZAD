### Array Types

```Bash
# 1D Array: A simple sequence of items
arr1d = np.array([10, 20, 30, 40])
arr1d.shape
(4,)

# 2D Array: A single grid/table
arr2d = np.array([[1, 2, 3], [4, 5, 6]])
arr2d.shape
(2, 3)

# 3D Array: A stack of 2D grids (Layers)
arr3d = np.zeros((2, 3, 4))
arr3d.shape
(2, 3, 4)

# 4D Array: Multiple 3D blocks (Batches)
arr4d = np.ones((5, 2, 3, 4))
arr4d.shape
(5, 2, 3, 4)

Identification: no.of brackets in begning '[' tell dimention
```
```text
1D = 1 row × C columns

2D = 1D + R rows
   = R × C

3D = 2D + L layers
   = L × R × C

4D = 3D + B batches
   = B × L × R × C

5D = 4D + G1 groups
   = G1 × B × L × R × C

6D = 5D + G2 groups
   = G2 × G1 × B × L × R × C

7D = 6D + G3 groups
   = G3 × G2 × G1 × B × L × R × C
```
In words
- 1D: 1 row containing multiple columns.
- 2D: multiple rows, each containing multiple columns.
- 3D: multiple layers, each layer contains multiple rows, each row contains multiple columns.
- 4D: multiple batches, each batch contains multiple layers → rows → columns.
- 5D: multiple groups, each group contains batches → layers → rows → columns.
- 6D: multiple G2 groups, each G2 contains G1 groups → batches → layers → rows → columns.
- 7D: multiple G3 groups, each G3 contains G2 → G1 → batches → layers → rows → columns.

So the key idea is:\
Every new dimension adds one new level outside the previous dimension.

### PCA Concept Using NumPy
`Principal Component Analysis involves:`
1. Center data
2. Calculate covariance matrix
3. Calculate eigenvalues/eigenvectors
4. Sort components
5. Project data
```bash
X_centered = X - X.mean(axis=0)

cov = np.cov(X_centered, rowvar=False)

eigenvalues, eigenvectors = np.linalg.eigh(cov)
# sorting its components
idx = np.argsort(eigenvalues)[::-1]

eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]
```

### Normal (Gaussian) Distribution
```text
The Normal Distribution is one of the most important distributions, also called the Gaussian Distribution after the German mathematician Carl Friedrich Gauss.

It fits the probability distribution of many events, eg. IQ Scores, Heartbeat etc.

Use the random.normal() method to get a Normal Data Distribution.

It has three parameters:

loc - (Mean) where the peak of the bell exists.

scale - (Standard Deviation) how flat the graph distribution should be.

size - The shape of the returned array.
```
```bash
# Generate a random normal distribution of size 2x3
```

### Binomial Distribution
```
Binomial Distribution is a Discrete Distribution, describes the outcome of binary scenarios, e.g. toss of a coin, it will either be head or tails.

It has three parameters:

n - number of trials.

p - probability of occurrence of each trial (e.g. for toss of a coin 0.5 each).

size - The shape of the returned array.

Discrete Distribution:The distribution is defined at separate set of events, e.g. a coin toss's result is discrete as it can be only head or tails whereas height of people is continuous as it can be 170, 170.1, 170.11 and so on.
```

```bash
x = random.binomial(n=10, p=0.5, size=10)
print(x) # Given 10 trials for coin toss generate 10 data points
```
### Difference Between Normal and Binomial Distribution
The main difference is that normal distribution is continous whereas binomial is discrete, but if there are enough data points it will be quite similar to normal distribution with certain loc and scale.

### Outlier Detection with NumPy
```bash
q1 = np.percentile(x, 25)
q3 = np.percentile(x, 75)

iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

outliers = x[(x < lower) | (x > upper)]
```
