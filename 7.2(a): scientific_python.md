```Bash
# The central object in NumPy is: ndarray -> A fixed-type, multidimensional container of numerical data.
numpy.ndarray
```

```Bash
# Array Types
a = np.array([10, 20, 30, 40])                          # 1-D Array

a = np.array([
    [1, 2, 3],
    [4, 5, 6]])                                         # 2-D Array

a = np.array([
    [
        [1, 2],
        [3, 4]
    ],
    [
        [5, 6],
        [7, 8]
    ]
])                                                    # 3-D Array
```

```Bash
# Properties or attributes
a = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(a.ndim)           # 2 (dimention)
print(a.shape)          # (2,3) (size along each dim)
print(a.size)           # 6 (total no of elements)
print(a.dtype)          # int64 (data type)
print(a.itemsize)       # 8 (byte per element)
print(a.nbytes)         # 48 (Total memory consumed)
```

```Bash
# Special Array
np.zeros(5)         # Zero array
np.ones((3, 4))     # ones array of dim 3,4
np.full((3, 3), 7)  # array of 7 dim 3,3
np.empty((2, 3))    # empty array dim 2,3
np.eye(4)           # Identity matrix
np.arange(0, 10)    # array in range of index
np.arange(0, 10, 2) # array within range of index with step 2
np.arange(0, 1, 0.1) # array within range of index with step 0.1
```

```Bash

```

```Bash
# Logrithmic space usefull in Hyperparameter search, Scientific computing, Log-scale plots
```

```Bash
# Data Types: NumPy arrays usually contain elements of the same data type.
`int8, int16, int32, int64`, `uint8, uint16, uint32, uint64`,`float16, float32, float64`, `complex64, complex128`, `bool`

a = np.array([1, 2, 3], dtype=np.float32)
print(a.dtype)
```

```Bash
# Data type affects:
`Memory`, `Speed`,`Precision`,`Compatibility`
a = np.array([1, 2, 3], dtype=np.int8) # Each value requires only 1 byte.
a = np.array([1, 2, 3], dtype=np.int64) # Each value requires only 8 byte.
```

```Bash
# Type Conversion `astype()`
a = np.array([1, 2, 3])
b = a.astype(np.float64)
print(b)
print(b.dtype)


a = np.array([1.2, 2.7, 3.9])
b = a.astype(int)
```

```Bash
# Reshaping
a = np.arange(12)

```

```Bash
# Automatic dimention calculation
a = np.arange(12)
a.reshape(3, -1) # 3,4

```

```Bash
# flatten, revel, transpose of an array

b = a.ravel() # ravel() is often more memory efficient.
b = a.T             #Transpose of array
```
