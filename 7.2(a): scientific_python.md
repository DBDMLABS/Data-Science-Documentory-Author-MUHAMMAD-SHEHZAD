### Array Types

```Bash
# 1D Array: A simple sequence of items
arr1d = np.array([10, 20, 30, 40])
arr1d.shape
(4,)

# 2D Array: A single grid/table
arr2d = np.array([[1, 2, 3], [4, 5, 6]])
arr2d.shape
(2, 3)

# 3D Array: A stack of 2D grids (Layers)
arr3d = np.zeros((2, 3, 4))
arr3d.shape
(2, 3, 4)

# 4D Array: Multiple 3D blocks (Batches)
arr4d = np.ones((5, 2, 3, 4))
arr4d.shape
(5, 2, 3, 4)

Identification: no.of brackets in begning '[' tell dimention
```
```text
1D = 1 row × C columns

2D = 1D + R rows
   = R × C

3D = 2D + L layers
   = L × R × C

4D = 3D + B batches
   = B × L × R × C

5D = 4D + G1 groups
   = G1 × B × L × R × C

6D = 5D + G2 groups
   = G2 × G1 × B × L × R × C

7D = 6D + G3 groups
   = G3 × G2 × G1 × B × L × R × C
```
In words
- 1D: 1 row containing multiple columns.
- 2D: multiple rows, each containing multiple columns.
- 3D: multiple layers, each layer contains multiple rows, each row contains multiple columns.
- 4D: multiple batches, each batch contains multiple layers → rows → columns.
- 5D: multiple groups, each group contains batches → layers → rows → columns.
- 6D: multiple G2 groups, each G2 contains G1 groups → batches → layers → rows → columns.
- 7D: multiple G3 groups, each G3 contains G2 → G1 → batches → layers → rows → columns.

So the key idea is:\
Every new dimension adds one new level outside the previous dimension.

| Array Type |    Example Shape | Slicing Syntax       | Meaning                              | Example          | Result / Shape            |
| ---------- | ---------------: | -------------------- | ------------------------------------ | ---------------- | ------------------------- |
| **1D**     |           `(6,)` | `a[:]`               | Select all elements                  | `a[:]`           | All 6 elements            |
| **1D**     |           `(6,)` | `a[start:stop]`      | Select a range                       | `a[1:4]`         | Elements at indices 1,2,3 |

| **1D**     |           `(6,)` | `a[:stop]`           | Beginning → stop                     | `a[:3]`          | First 3 elements          |
| **1D**     |           `(6,)` | `a[start:]`          | Start → end                          | `a[3:]`          | Last 3 elements           |
| **1D**     |           `(6,)` | `a[::-1]`            | Reverse                              | `a[::-1]`        | All elements reversed     |
| **1D**     |           `(6,)` | `a[-3:]`             | Last 3                               | `a[-3:]`         | Last 3 elements           |
| **2D**     |          `(3,4)` | `a[:]`               | All rows and columns                 | `a[:]`           | `(3,4)`                   |
| **2D**     |          `(3,4)` | `a[row]`             | Select one row                       | `a[1]`           | `(4,)`                    |
| **2D**     |          `(3,4)` | `a[:,col]`           | Select one column                    | `a[:,2]`         | `(3,)`                    |
| **2D**     |          `(3,4)` | `a[r1:r2,c1:c2]`     | Select rows + columns                | `a[0:2,1:3]`     | `(2,2)`                   |
| **2D**     |          `(3,4)` | `a[:,:]`             | All rows + columns                   | `a[:,:]`         | `(3,4)`                   |
| **2D**     |          `(3,4)` | `a[::2,:]`           | Every 2nd row                        | `a[::2,:]`       | Selected rows             |
| **2D**     |          `(3,4)` | `a[:,::2]`           | Every 2nd column                     | `a[:,::2]`       | Selected columns          |
| **2D**     |          `(3,4)` | `a[::-1,:]`          | Reverse rows                         | `a[::-1,:]`      | Rows reversed             |
| **2D**     |          `(3,4)` | `a[:,::-1]`          | Reverse columns                      | `a[:,::-1]`      | Columns reversed          |
| **3D**     |        `(2,3,4)` | `a[:]`               | Select everything                    | `a[:]`           | `(2,3,4)`                 |
| **3D**     |        `(2,3,4)` | `a[i]`               | Select one 2D block                  | `a[0]`           | `(3,4)`                   |
| **3D**     |        `(2,3,4)` | `a[i,j]`             | Select one row inside block          | `a[0,1]`         | `(4,)`                    |
| **3D**     |        `(2,3,4)` | `a[i,j,k]`           | Select one element                   | `a[0,1,2]`       | Scalar                    |
| **3D**     |        `(2,3,4)` | `a[:,:,k]`           | Select one column across blocks      | `a[:,:,1]`       | `(2,3)`                   |
| **3D**     |        `(2,3,4)` | `a[:,j,:]`           | Select one row across blocks         | `a[:,1,:]`       | `(2,4)`                   |
| **3D**     |        `(2,3,4)` | `a[i,:,:]`           | Select one complete block            | `a[1,:,:]`       | `(3,4)`                   |

| **3D**     |        `(2,3,4)` | `a[:,::2,:]`         | Every 2nd row in each block          | `a[:,::2,:]`     | Reduced row dimension     |
| **3D**     |        `(2,3,4)` | `a[:,:,::2]`         | Every 2nd column                     | `a[:,:,::2]`     | Reduced last dimension    |
| **N-D**    | `(d1,d2,...,dn)` | `a[:]`               | Everything                           | `a[:]`           | Same shape                |
| **N-D**    | `(d1,d2,...,dn)` | `a[i]`               | Select first dimension               | `a[0]`           | Removes first dimension   |
| **N-D**    | `(d1,d2,...,dn)` | `a[i,j]`             | Select first 2 dimensions            | `a[0,1]`         | Remaining dimensions      |
| **N-D**    | `(d1,d2,...,dn)` | `a[i,j,k]`           | Select first 3 dimensions            | `a[0,1,2]`       | Remaining dimensions      |

| **N-D**    | `(d1,d2,...,dn)` | `a[:,...,k]`         | All of first dimension + last index  | `a[:,...,0]`     | Depends on shape          |
| **N-D**    | `(d1,d2,...,dn)` | `a[::2,...]`         | Every 2nd element of first dimension | `a[::2,...]`     | Reduced first dimension   |
| **N-D**    | `(d1,d2,...,dn)` | `a[...,::-1]`        | Reverse last dimension               | `a[...,::-1]`    | Last dimension reversed   |

```bash
np.diff(a) # Difference between consecutive elements

Examples:

np.diff([1, 2, 4, 7])
#[1, 2, 3]

np.cumsum([1, 2, 3, 4])
#[1, 3, 6, 10]

np.cumprod([1, 2, 3, 4])
#[1, 2, 6, 24]
```
