### Checking the Data Type

Use `type(value_or_variable)` to see the type of any value.

```python
print(type(10))                    # <class 'int'>
print(type(3.14))                  # <class 'float'>
print(type(2 + 3j))                # <class 'complex'>

print(type(True))                  # <class 'bool'>
print(type(False))                 # <class 'bool'>

print(type('Python'))              # <class 'str'>
# Single quotes  'text'      -> single-line string
# Double quotes  "text"      -> single-line string (same as single quotes)
# Triple quotes  '''text''' or """text""" -> multi-line string

print(type([1, 2, 3]))             # <class 'list'>
print(type((1, 2, 3)))             # <class 'tuple'>
print(type(range(5)))              # <class 'range'>

print(type({1, 2, 3}))             # <class 'set'>
print(type(frozenset({1, 2, 3})))  # <class 'frozenset'>

print(type({"name": "Shehzad", "age": 20}))  # <class 'dict'>

print(type(b"Python"))             # <class 'bytes'>
print(type(bytearray(5)))          # <class 'bytearray'>
print(type(memoryview(bytes(5))))  # <class 'memoryview'>
# Put b before a string to make bytes: b"Python"
# Use bytearray() for a mutable sequence of bytes
# Use memoryview() to view the memory of a bytes-like object without copying it

print(type(None))                  # <class 'NoneType'>
```

### Type Conversion (Type Casting)

```python
int("10")        # str   -> int      : 10
float("10.5")    # str   -> float    : 10.5
str(100)         # int   -> str      : '100'
float(10)        # int   -> float    : 10.0
int(10.5)        # float -> int      : 10 (the decimal part is cut off, not rounded)
list("ABC")      # str   -> list     : ['A', 'B', 'C']
tuple([1, 2])    # list  -> tuple    : (1, 2)
set([1, 2, 2])   # list  -> set      : {1, 2} (duplicates removed)
bool(1)          # int   -> bool     : True  (bool(0) is False)
complex(3)       # int   -> complex  : (3+0j)

x = 23
complex(x)       # (23+0j)

# To see the results, wrap them in print(), for example:
print(int("10"), type(int("10")))   # 10 <class 'int'>
```

### Checking Types with isinstance()

`isinstance(value, type)` returns `True` if the value is of that type (or a subclass of it).

```python
x = 10
print(isinstance(x, int))             # True
print(isinstance(x, (int, float)))    # True - checks against several types
print(isinstance("10", int))          # False
```

### Checking Classes with issubclass()

`issubclass(class_a, class_b)` returns `True` if `class_a` inherits from `class_b`.

```python
print(issubclass(int, object))   # True - every class inherits from object
print(issubclass(bool, int))     # True - bool is a subclass of int
print(issubclass(str, int))      # False
```

## Variables

### Dynamic Variables

Python variables do not have a fixed type. The same variable can refer to objects of different types.

```python
x = 10          # int
x = "Python"    # now a str
x = 3.14        # now a float
print(type(x))  # <class 'float'>
```

### Multiple Assignment (Parallel and Chained)

```python
x, y = 10, 20    # Parallel: assign several values at once
a = b = c = 0    # Chained: give the same value to several variables

# Swap two variables in one line
x, y = y, x
print(x, y)      # 20 10
```

### Variable Naming Rules

| Rule | Valid | Invalid |
|---|---|---|
| Use letters, numbers and underscores only | `student_name` | `student-name` |
| Must start with a letter or `_` (never a number) | `_count`, `age2` | `2age` |
| No spaces or special characters | `total_marks` | `total marks`, `price$` |
| Cannot be a Python keyword | `class_name` | `class`, `for`, `if` |
| Names are case-sensitive | `Age` and `age` are two different variables | |


### Reassignment

```python
x = 10
x = 70
print(x)   # 70 - the last assignment is kept
```

### Compound Assignment

```python
x = 10
x += 5     # x = x + 5   -> 15
x -= 5     # x = x - 5   -> 10
x *= 5     # x = x * 5   -> 50
x /= 5     # x = x / 5   -> 10.0 (/ always gives a float)
x //= 5    # x = x // 5  -> 2.0
x %= 5     # x = x % 5   -> 2.0
x **= 2    # x = x ** 2  -> 4.0
print(x)   # 4.0
```

### Augmented Assignment Examples

Compound (augmented) assignment works with many types, not only numbers.

```python
counter = 0
counter += 1            # increase a counter
print(counter)          # 1

numbers = [1, 2, 3]
numbers += [4, 5]       # extend a list
print(numbers)          # [1, 2, 3, 4, 5]

READ, WRITE = 4, 2      # permission flags stored as bits
permissions = READ
permissions |= WRITE    # bitwise OR: add the WRITE flag
print(permissions)      # 6
```

## Strings

A string (`str`) is an ordered, **immutable** sequence of characters.

### Creating Strings

```python
name = "Python"
text = "  Python Programming  "   # with extra spaces (used below)
multi = """This is
a multi-line string"""
```

### Indexing

Indexes start at `0`. Negative indexes count from the end.

```python
print(name[0])    # P
print(name[-1])   # n
```

### Slicing

`string[start:stop:step]` - `stop` is **not** included.

```python
print(name[1:4])  # yth
print(name[:2])   # Py
print(name[2:])   # thon
```

### Length

```python
print(len(name))  # 6
```

### Concatenation

```python
print("Hello " + name)        # Hello Python
print("Hello" + " " + name)   # Hello Python  (" " adds a space)
print("Hello" + "" + name)    # HelloPython   ("" adds nothing)
```

### Repetition

```python
print("Hi " * 3)   # Hi Hi Hi
```

### Removing Whitespace

```python
clean_text = text.strip()   # removes spaces from both ends
print(clean_text)           # Python Programming
# lstrip() -> left side only, rstrip() -> right side only
```

### Case Conversion

```python
print(clean_text.upper())   # PYTHON PROGRAMMING
print(clean_text.lower())   # python programming
print(clean_text.title())   # Python Programming
```

### Searching

`find()` returns the index of the first match, or `-1` if not found.

```python
print(name.find("t"))                    # 2
print(clean_text.find("Programming"))    # 7
print(name.find("z"))                    # -1
print("Py" in name)                      # True
```

### Splitting

`split(separator)` breaks a string into a list.

```python
print("a,b,c".split(","))        # ['a', 'b', 'c']
print("abc".split(","))          # ['abc'] - no comma, so one item
print("Data Science".split())    # ['Data', 'Science'] - splits on whitespace
```

### Joining

```python
print("-".join(["a", "b", "c"]))   # a-b-c
```

### Validation

```python
print("123".isdigit())    # True
print("abc".isalpha())    # True
print("abc1".isalnum())   # True
print("12.5".isdigit())   # False - "." is not a digit
```

### Formatting

```python
age = 20
print(f"I am {age} years old.")   # I am 20 years old.
```

### Replacing

```python
print(clean_text.replace("Python", "Java"))   # Java Programming
```

### Reversing

```python
print(name[::-1])   # nohtyP  (step -1 walks backwards)
```

> **Note:** String methods never change the original string (strings are immutable). They return a **new** string, so save the result: `name = name.upper()`.

## Numbers and Math

### Arithmetic Operators

| Operator | Meaning | Example | Result |
|---|---|--:|--:|
| `+` | Addition | `10 + 3` | `13` |
| `-` | Subtraction | `10 - 3` | `7` |
| `*` | Multiplication | `10 * 3` | `30` |
| `/` | Division (always a float) | `10 / 3` | `3.333...` |
| `//` | Floor division | `10 // 3` | `3` |
| `%` | Remainder (modulus) | `10 % 3` | `1` |
| `**` | Power | `10 ** 3` | `1000` |

> **Note:** Floor division rounds the result **down toward negative infinity**.
> For example, `-5 // 2` is `-3` (because -2.5 is floored to -3) and `5 // 2` is `2` (2.5 is floored to 2).

### Order of Operations

Python follows the `PEMDAS` / `BODMAS` idea:

| Priority | Operators |
|---|---|
| 1 (highest) | `()` Parentheses |
| 2 | `**` Power |
| 3 | `+x`, `-x` (unary plus/minus) |
| 4 | `*`, `/`, `//`, `%` (left to right) |
| 5 (lowest) | `+`, `-` (left to right) |


### Assignment Operators

| Operator | Meaning | Example | Same as |
|---|---|---|---|
| `=` | Assign | `x = 2` | `x = 2` |
| `+=` | Add and assign | `x += 2` | `x = x + 2` |
| `-=` | Subtract and assign | `x -= 2` | `x = x - 2` |
| `*=` | Multiply and assign | `x *= 2` | `x = x * 2` |
| `/=` | Divide and assign | `x /= 2` | `x = x / 2` |
| `//=` | Floor divide and assign | `x //= 2` | `x = x // 2` |
| `%=` | Modulus and assign | `x %= 2` | `x = x % 2` |
| `**=` | Power and assign | `x **= 2` | `x = x ** 2` |

### Comparison Operators

Comparison operators always return `True` or `False`.

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `==` | Equal to | `5 == 5` | `True` |
| `!=` | Not equal to | `5 != 3` | `True` |
| `>` | Greater than | `5 > 3` | `True` |
| `<` | Less than | `5 < 3` | `False` |
| `>=` | Greater than or equal to | `5 >= 5` | `True` |
| `<=` | Less than or equal to | `3 <= 2` | `False` |

> **Tip:** Python allows chained comparisons: `1 <= age <= 100`.

### Taking Input

`input()` always returns a **string**.

```python
age = input("Enter your age: ")
print(type(age))   # <class 'str'>

# Add two numbers taken as input (convert them to int first)
x = int(input("Enter your age: "))
y = int(input("Enter your DS experience in years: "))
total = x + y      # avoid naming it "sum" - that hides the built-in sum()
print("Total:", total)
```

### Useful Built-in Math Functions

| Function | Purpose | Example | Result |
|---|---|---|---|
| `abs()` | Absolute value | `abs(-4)` | `4` |
| `round()` | Round a number | `round(3.567, 1)` | `3.6` |
| `pow()` | Power of a number | `pow(2, 3)` | `8` |
| `divmod()` | Quotient and remainder | `divmod(17, 5)` | `(3, 2)` |
| `min()` | Smallest value | `min(4, 9, 1)` | `1` |
| `max()` | Largest value | `max(4, 9, 1)` | `9` |
| `sum()` | Add numbers in an iterable | `sum([1, 2, 3])` | `6` |

> - Absolute value is the distance from zero: `|-4| = 4`
> - `pow(2, 3)` means 2 to the power 3 = `2 * 2 * 2 = 8`

#### Rounding

Python uses **"round half to even"** (also called **banker's rounding**): a number exactly halfway is rounded to the nearest **even** number.

```python
print(round(2.5))          # 2  (2 is even)
print(round(3.5))          # 4  (4 is even)
print(round(3.14159, 2))   # 3.14

# Rounding to negative decimals rounds to tens, hundreds, ...
print(round(1234.567, -2)) # 1200.0
```

#### Modular Exponentiation

```python
print(pow(2, 10, 1000))   # 24
# 2 power 10 mod 1000 = 1024 mod 1000 = 24
# Faster than (2 ** 10) % 1000 for very large numbers
```

#### Quotient and Remainder with divmod()

```python
result = divmod(17, 5)
print(result)   # (3, 2) -> 17 // 5 = 3, 17 % 5 = 2
```

#### Square Root

```python
import math
import cmath

print(math.sqrt(16))   # 4.0
print(math.sqrt(2))    # 1.4142135623730951
print(math.isqrt(17))  # 4 - integer square root (rounded down)

# Square root of a negative number
# math.sqrt(-1)        # ValueError: math domain error
print(cmath.sqrt(-1))  # 1j
```

#### Constants

```python
print(math.pi)   # 3.141592653589793
```

#### Ceiling and Floor

- **Ceiling** returns the smallest integer `>=` the number.
- **Floor** returns the greatest integer `<=` the number.

```python
print(math.ceil(3.2))    # 4
print(math.ceil(-3.2))   # -3

print(math.floor(3.2))   # 3
print(math.floor(-3.2))  # -4
```

### Floating-Point Precision

Floating-point numbers are stored in binary. Some decimal values (like `0.1`) cannot be stored exactly, so the computer stores an approximation.

```python
print(0.1 + 0.2)   # 0.30000000000000004 (we expect 0.3)

# Comparing floats with == is unsafe
a = 0.1 + 0.2
if a == 0.3:
    print("Equal")             # does NOT print

# Use math.isclose() instead
if math.isclose(a, 0.3):
    print("Approximately equal")   # prints
```

#### Using Tolerance

**Tolerance** = the maximum acceptable difference between two values.

```python
# rel_tol: Relative tolerance - based on the size of the numbers
# (default rel_tol=1e-09)
print(math.isclose(1.000001, 1.000002, rel_tol=1e-5))   # True

# abs_tol: Absolute tolerance - a fixed acceptable difference
# Needed when comparing with 0, because rel_tol alone never matches 0
print(math.isclose(0.0000001, 0, abs_tol=1e-6))         # True

# Both together: passes if the difference is within EITHER tolerance
a = 0.000001
b = 0.0000011

print(math.isclose(a, b, rel_tol=0.01, abs_tol=0.0000001))   # False
# The difference is 1.000000000000001e-07, a tiny bit MORE than abs_tol,
# and rel_tol (1% of 0.0000011) is even smaller. Loosen abs_tol:
print(math.isclose(a, b, rel_tol=0.01, abs_tol=0.000001))    # True
```

| Parameter | Meaning | Example |
|---|---|---|
| `a` | First number | `10.0` |
| `b` | Second number | `10.01` |
| `rel_tol` | Relative tolerance | `0.001` |
| `abs_tol` | Absolute tolerance | `0.01` |

### Bitwise Operators

Bitwise operators work on the **binary** representation of integers.

| Operator | Name | Example (`a = 5` = `101`, `b = 3` = `011`) | Result |
|---|---|---|---|
| `&` | AND | `a & b` → `001` | `1` |
| `\|` | OR | `a \| b` → `111` | `7` |
| `^` | XOR | `a ^ b` → `110` | `6` |
| `~` | NOT | `~a` | `-6` |
| `<<` | Left shift | `a << 1` → `1010` | `10` |
| `>>` | Right shift | `a >> 1` → `10` | `2` |

```python
a = 5   # 101 in binary
b = 3   # 011 in binary

print(a & b)    # 1
print(a | b)    # 7
print(a ^ b)    # 6
print(~a)       # -6  (~x is always -(x + 1))
print(a << 1)   # 10  (same as a * 2)
print(a >> 1)   # 2   (same as a // 2)
print(bin(a))   # 0b101
```

### Logical Operators

Logical operators (`and`, `or`, `not`) combine `True`/`False` values. Do not confuse them with the bitwise operators above.

```python
age = 25
has_id = True

print(age < 18 or has_id)     # True
print(not has_id)             # False
```

| A | B | A and B | A or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

## Control Flow

**Control flow** means the order in which Python executes the statements of a program. By default, Python runs code from **top to bottom**, one line after another.

### What Control Flow Statements Do

Control flow statements allow us to:
- Make decisions
- Repeat code
- Skip specific statements
- Stop loops
- Handle different execution paths (including errors)

### Control Flow Structure

```text
Control Flow
│
├── Conditional Statements
│   ├── if
│   ├── if-else
│   ├── if-elif-else
│   └── Nested if
│
├── Looping Statements
│   ├── for loop
│   ├── while loop
│   └── Nested loops
│
├── Loop Control Statements
│   ├── break
│   ├── continue
│   └── pass
│
└── Other Control-Flow Features
    ├── match-case
    ├── Exception handling
    └── Conditional expressions
```

### Conditional Statements

> **Important Point:** Every `if`, `elif`, `else`, `for`, `while`, `def` and `class` line ends with a colon `:`, and the block under it must be **indented** (4 spaces is standard).

#### if Statement

```python
# Syntax
if condition:
    statement

# Example
age = 20
if age >= 18:
    print("You are an adult")   # You are an adult
```

#### if-else Statement

```python
# Syntax
if condition:
    statement_if_condition_true
else:
    statement_if_condition_false

# Example
number = 7
if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")         # Odd number
```

#### if-elif-else Statement

```python
# Syntax
if condition1:
    statement1
elif condition2:
    statement2
elif condition3:
    statement3
else:
    default_statement

# Example
marks = 72
if marks >= 80:
    grade = "A+"
elif marks >= 70:
    grade = "A"
elif marks >= 60:
    grade = "B"
elif marks >= 50:
    grade = "C"
elif marks >= 40:
    grade = "D"
else:
    grade = "F"

print(grade)   # A
```

- Conditions are checked from top to bottom.
- The block of the **first** true condition runs, and the remaining conditions are skipped.
- If no condition is true, the `else` block runs.

#### Nested if Statement

An `if` statement inside another `if` statement is called a **nested if**.

```python
# Syntax
if condition1:
    if condition2:
        statement_true
    else:
        statement_false
else:
    statement2

# Example
age = 25
has_license = True
if age >= 18:
    if has_license:
        print("You can drive")        # You can drive
    else:
        print("You need a license")
else:
    print("You are underage")

# Better alternative: combine the conditions with "and"
if age >= 18 and has_license:
    print("You can drive")
else:
    print("You cannot drive")
```

#### Combining Conditions

```python
# and -> ALL conditions must be true
age = 22
income = 50000
if age >= 18 and income >= 30000:
    print("Eligible")                 # Eligible
else:
    print("Not eligible")

# or -> AT LEAST ONE condition must be true
day = "Friday"
if day == "Friday" or day == "Saturday":
    print("Weekend is near")          # Weekend is near

# Shorter with "in"
if day in ("Friday", "Saturday"):
    print("Weekend is near")
```

#### Conditional Expression

A conditional expression (ternary operator) is a one-line form of `if-else`.

```python
# Syntax
# value_if_true if condition else value_if_false

age = 15
status = "Adult" if age >= 18 else "Minor"
print(status)   # Minor
```

### Loops

#### for Loop

A `for` loop repeats a block of code **for each item** in an iterable.

An iterable can be a:
- String
- List
- Tuple
- Set
- Dictionary
- Range
- File
- Other iterable objects

```python
# Syntax
for variable in iterable:
    statement

# Example 1
for number in [1, 2, 3, 4, 5]:
    print(number)       # 1 2 3 4 5 (each on a new line)

# Example 2
for character in "Python":
    print(character)    # P y t h o n (each on a new line)
```

#### The range() Function

`range()` creates a sequence of numbers and is commonly used with `for` loops. The `stop` value is **never** included.

```python
# One argument: range(stop) -> 0 to stop-1
for i in range(5):
    print(i)            # 0 1 2 3 4

# Two arguments: range(start, stop)
for i in range(2, 6):
    print(i)            # 2 3 4 5

# Three arguments: range(start, stop, step)
for i in range(0, 10, 3):
    print(i)            # 0 3 6 9

# Decreasing range (negative step)
for i in range(10, 0, -1):
    print(i)            # 10 9 8 ... 1

# for loop with else: else runs when the loop finishes WITHOUT break
for i in range(5):
    print(i)
else:
    print("Loop completed")
```

#### while Loop

A `while` loop repeats code **as long as** a condition is true.

```python
# Syntax
while condition:
    statement

# Example
count = 1

while count <= 5:
    print(count)        # 1 2 3 4 5
    count += 1
```

How it works:
1. Check the condition.
2. If true, execute the body.
3. Update the loop variable.
4. Check the condition again.
5. Stop when the condition becomes false.

> **Important Point:** Avoid infinite loops. An **infinite loop** never ends because its condition always stays true. Press `Ctrl + C` to stop one.

```python
# WRONG - infinite loop: count is never updated, so count <= 5 is always True
count = 1
while count <= 5:
    print(count)
    # missing: count += 1

# while loop with else: else runs when the condition becomes false (no break)
count = 1
while count <= 3:
    print(count)
    count += 1
else:
    print("Loop completed")
```

#### for vs while

| `for` Loop | `while` Loop |
|---|---|
| Used to iterate over an iterable | Used while a condition is true |
| Usually used when the number of repetitions is known | Useful when the number of repetitions is unknown |
| Automatically moves to the next item | Requires manual condition updates |
| Works naturally with strings, lists, ranges, etc. | Works with any Boolean condition |
| Less likely to become infinite | Can easily become infinite |

### Task: Check a Prime Number

A prime number is greater than 1 and divisible only by 1 and itself.

```python
number = int(input("Enter number: "))

if number < 2:
    print("Not prime")
else:
    prime = True

    for i in range(2, number):
        if number % i == 0:
            prime = False
            break

    if prime:
        print("Prime")
    else:
        print("Not prime")

# Find all primes between 1 and 50
for n in range(2, 51):
    for i in range(2, int(n ** 0.5) + 1):

            break           # found a divisor -> not prime
    else:
        print(n, end=" ")   # runs only if the inner loop did NOT break

# Output:

```

## Functions

A **function** is a reusable block of code that performs a specific task. Instead of writing the same code again and again, we define it once and call it whenever we need it.

### Basic Function

```python
def greet():
    print("Hello!")

greet()   # Hello!

# def          -> defines a function
# ()           -> parameters go here
# indentation  -> the function body
```

### Function with a Parameter

```python
def greet(name):
    print("Hello", name)

greet("Ali")   # Hello Ali

# name  = parameter (the variable in the definition)
# "Ali" = argument  (the value passed in the call)
```

### Multiple Parameters

```python
def add(a, b):
    return a + b

result = add(10, 20)
print(result)   # 30

# Arguments are matched to parameters by position,
# unless keyword arguments are used.
```

### return

`return` sends a value back to the caller and **immediately ends** the function.

```python
def square(x):
    return x * x

answer = square(5)
print(answer)   # 25

# print()  -> displays something on the screen
# return   -> gives a value back that you can store and reuse
# A function without return gives back None.
```

### Default Parameter

```python
def greet(name="Guest"):
    print("Hello", name)

greet()        # Hello Guest  (no argument -> default is used)
greet("Ali")   # Hello Ali
```

> **Important Point:** Do not use a mutable default like `def f(items=[])`. The same list is shared between calls. Use `items=None` and create the list inside the function.

### Keyword Arguments

```python
def student(name, age):
    print(name, age)

student(age=20, name="Ali")   # Ali 20

# Pass arguments using parameter names - the order does not matter.
```

### `*args`

`*args` accepts **any number of positional arguments** and stores them in a **tuple**.

```python
def add(*numbers):
    print(numbers)        # (10, 20, 30)
    return sum(numbers)

print(add(10, 20, 30))    # 60
```

### `**kwargs`

`**kwargs` accepts **any number of keyword arguments** and stores them in a **dictionary**.

```python
def student_info(**info):
    for key, value in info.items():
        print(key, ":", value)


student_info(name="Ali", age=20, city="Lahore")

# Output:
# name : Ali
# age : 20
# city : Lahore
```

### Local Variables

```python
def test():
    x = 10       # local variable
    print(x)

test()           # 10
# print(x)       # NameError: x exists only inside the function
```

### Global Variables

A variable created outside all functions can be **read** inside a function.

```python
x = 100

def show():
    print(x)

show()   # 100
```

### The global Keyword

Use `global` to **modify** a global variable from inside a function.

```python
x = 10

def change():
    global x
    x = 20

change()
print(x)   # 20
```

> **Tip:** Avoid unnecessary global variables. Prefer passing values as arguments and returning results.

### Lambda Functions

A **lambda** is a small anonymous (unnamed) function written in one line.

```python
# Syntax: lambda arguments: expression
square = lambda x: x * x
print(square(5))   # 25

# Lambdas are most useful as short arguments to other functions
names = ["Sara", "Ali", "Muhammad"]
print(sorted(names, key=lambda n: len(n)))   # ['Ali', 'Sara', 'Muhammad']
```

Best for short, simple operations. Use `def` for anything longer.

### Recursion

**Recursion** means a function calls itself. Every recursive function needs a **base case**, otherwise it keeps calling itself until Python raises a `RecursionError`.

```python
def countdown(n):
    if n == 0:       # Base case: stops the recursion
        return

    print(n)
    countdown(n - 1)

countdown(5)   # 5 4 3 2 1
```

```python
def factorial(n):
    if n == 0 or n == 1:   # Base case
        return 1

    return n * factorial(n - 1)


print(factorial(5))   # 120
```

### Docstrings

A **docstring** explains what a function does. It is written as the first statement inside the function.

```python
def add(a, b):
    """Return the sum of two numbers."""
    return a + b

print(add.__doc__)   # Return the sum of two numbers.
help(add)            # also shows the docstring
```

### Type Hints

Type hints show the expected input and output types.

```python
def add(a: int, b: int) -> int:
    return a + b

print(add(2, 3))       # 5
print(add("a", "b"))   # ab - type hints are NOT enforced by Python
```

> **Note:** Tools like Pylance (in VS Code) or `mypy` use type hints to warn you about mistakes before running the code.

### Functions with Loops

Functions can contain loops, conditions and any other code.

```python
def print_numbers(numbers):
    for number in numbers:
        print(number)

print_numbers([10, 20, 30])   # 10 20 30
```

| Function | Purpose | Example |
|---|---|---|
| `callable()` | Checks if an object can be called like a function | `callable(print)` → `True` |
| `dir()` | Lists the attributes and methods of an object | `dir(str)` |
| `globals()` | Dictionary of the current global symbol table | `globals()` |
| `hash()` | Hash value of an (immutable) object | `hash("abc")` |
| `id()` | Unique identifier (memory identity) of an object | `id(x)` |
| `locals()` | Dictionary of the current local symbol table | `locals()` |
| `repr()` | String representation for debugging | `repr("hi")` → `"'hi'"` |

## Comprehensions

A comprehension creates a collection (list, set, dictionary or generator) with a short, one-line syntax.

### List Comprehension

```python
# Syntax: [expression for item in iterable]
numbers = [x for x in range(5)]

print(numbers)

# Output:
# [0, 1, 2, 3, 4]
```

### List Comprehension with an Expression

Transform each item before adding it to the list.

```python
squares = [x * x for x in range(1, 6)]

print(squares)

# Output:
# [1, 4, 9, 16, 25]
```

### List Comprehension with if

Filter values: `[expression for item in iterable if condition]`

```python
even = [x for x in range(10) if x % 2 == 0]

print(even)

# Output:
# [0, 2, 4, 6, 8]
```

### if-else in a List Comprehension

Choose a value: `[value_if_true if condition else value_if_false for item in iterable]`

```python
result = [
    "Even" if x % 2 == 0 else "Odd"
    for x in range(5)
]

print(result)

# Output:
# ['Even', 'Odd', 'Even', 'Odd', 'Even']
```

### Strings and List Comprehension

Iterate through the characters of a string.

```python
word = "Python"

letters = [ch.upper() for ch in word]

print(letters)

# Output:
# ['P', 'Y', 'T', 'H', 'O', 'N']
```

### Nested List Comprehension

Flatten a nested list.

```python
matrix = [[1, 2], [3, 4], [5, 6]]

result = [x for row in matrix for x in row]

print(result)

# Output:
# [1, 2, 3, 4, 5, 6]

# Read it from left to right, like nested loops:
# for row in matrix:
#     for x in row:
#         add x
```

### Set Comprehension

Creates a **set**, so duplicates are removed automatically. Syntax: `{expression for item in iterable}`

```python
numbers = [1, 2, 2, 3, 3, 4]

squares = {x * x for x in numbers}

print(squares)

# Output (sets have no fixed order):
# {1, 4, 9, 16}
```

### Dictionary Comprehension

Syntax: `{key: value for item in iterable}`

```python
squares = {
    x: x * x
    for x in range(1, 6)
}

print(squares)

# Output:
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

### Dictionary Comprehension with a Condition

```python
even_squares = {
    x: x * x
    for x in range(10)
    if x % 2 == 0
}

print(even_squares)

# Output:
# {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}
```

### Generator Expression

A generator produces values **one at a time, when needed**. It does not build the whole collection in memory, which saves memory for large data.

```python
numbers = (x * x for x in range(5))

for number in numbers:
    print(number)

# Output:
# 0
# 1
# 4
# 9
# 16

# Useful directly inside functions like sum():
print(sum(x * x for x in range(5)))   # 30
```

> **Note:** A generator can be used only **once**. After you loop through it, it is empty.

### Normal Loop vs Comprehension

```python
# Normal loop
squares = []

for x in range(5):
    squares.append(x * x)


# Comprehension
squares = [x * x for x in range(5)]

# Both give [0, 1, 4, 9, 16]
```

> **Tip:** Use a comprehension when it makes the code clearer. Do not write complicated comprehensions just to save lines.

### Comprehension Quick Revision

| Syntax | Creates |
|---|---|
| `[x for x in data]` | List comprehension |
| `{x for x in data}` | Set comprehension |
| `{k: v for k, v in data}` | Dictionary comprehension |
| `(x for x in data)` | Generator expression |
| `[x for x in data if condition]` | `if` at the END → **filter** |
| `[A if condition else B for x in data]` | `if/else` BEFORE `for` → **choose a value** |

## Classes and Objects

**Object-Oriented Programming (OOP)** groups data (attributes) and behaviour (methods) together into objects.

### Class

A **class** is a blueprint/template for creating objects.

```python
class Student:
    pass
```

### Object

An **object** is an instance created from a class.

```python
s1 = Student()
print(type(s1))   # <class '__main__.Student'>
```

### The Constructor

The constructor `__init__()` initializes the object's data. It runs **automatically** when an object is created.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

s1 = Student("Ali", 20)
```

### The self Parameter

`self` refers to the **current object**. Python passes it automatically - you do not write it when calling a method.

```python
print(s1.name)   # Ali
print(s1.age)    # 20
```

### Attributes

An **attribute** is data that belongs to an object.

```python
self.name    # instance attribute (inside the class)
self.age

s1.name      # accessing it from outside
```

### Methods

A **method** is a function defined inside a class.

```python
class Student:
    def introduce(self):
        print("Hello")

s1 = Student()
s1.introduce()   # Hello
```

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def display(self):
        print("Name:", self.name)
        print("Age:", self.age)


student1 = Student("Ali", 20)

student1.display()

# Output:
# Name: Ali
# Age: 20
```

### Class Variables

A **class variable** is shared by all objects of the class.

```python
class Student:
    university = "ABC University"   # class variable

    def __init__(self, name):
        self.name = name            # instance variable (different per object)

print(Student.university)           # ABC University
s1 = Student("Ali")
print(s1.university)                # ABC University (shared)
```

### Inheritance

**Inheritance** lets a child class reuse the functionality of a parent class.

```python
class Animal:
    def speak(self):
        print("Sound")

class Dog(Animal):   # Dog inherits from Animal
    pass

d = Dog()
d.speak()            # Sound
```

### Method Overriding

A child class can provide its **own version** of a parent's method.

```python
class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    def speak(self):
        print("Bark")

d = Dog()
d.speak()   # Bark
```

### super()

`super()` gives access to the parent class's methods.

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)     # Call the parent constructor
        self.breed = breed

d = Dog("Tommy", "Labrador")
print(d.name, d.breed)   # Tommy Labrador
```

### Class Methods

A **class method** works with class-level data. It receives `cls` (the current class) instead of `self`.

```python
class Student:
    school = "ABC"

    @classmethod
    def change_school(cls, name):
        cls.school = name

Student.change_school("XYZ")
print(Student.school)   # XYZ
```

### Static Methods

A **static method** is a utility method. It does not need `self` or `cls`.

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b

print(Math.add(5, 3))   # 8
```

| Method type | First parameter | Decorator | Used for |
|---|---|---|---|
| Instance method | `self` | none | Working with object data |
| Class method | `cls` | `@classmethod` | Working with class data |
| Static method | none | `@staticmethod` | Utility functions related to the class |

## Collections

### Lists

Purpose: an **ordered** and **changeable** collection.

```python
numbers = [10, 20, 30]

print(numbers[0])        # 10 (indexing)

numbers.append(40)       # Add at end          -> [10, 20, 30, 40]
numbers.insert(1, 15)    # Add at position     -> [10, 15, 20, 30, 40]
numbers.remove(20)       # Remove a value      -> [10, 15, 30, 40]
numbers.pop()            # Remove last item    -> [10, 15, 30]
numbers.sort()           # Sort ascending      -> [10, 15, 30]
numbers.reverse()        # Reverse the order   -> [30, 15, 10]
print(numbers)           # [30, 15, 10]

numbers.clear()          # Remove all items    -> []
# print(numbers[0])      # IndexError: the list is now empty
```

| Property | Value |
|---|---|
| Ordered | Yes |
| Mutable | Yes |
| Duplicates | Yes |
| Indexing | Yes |

### Tuples

Purpose: an **ordered** and **unchangeable** collection.

```python
numbers = (10, 20, 30)

print(numbers[0])        # 10 (indexing)

# numbers[0] = 100       # TypeError: a tuple cannot be modified

single = (5,)            # a one-item tuple needs a trailing comma
```

| Property | Value |
|---|---|
| Ordered | Yes |
| Mutable | No |
| Duplicates | Yes |
| Indexing | Yes |

### Sets

Purpose: store **unique** values.

```python
numbers = {10, 20, 30, 20}

print(numbers)           # {10, 20, 30} - the duplicate 20 is kept only once

numbers.add(40)          # Add an item            -> {10, 20, 30, 40}
numbers.remove(20)       # Remove (KeyError if missing) -> {10, 30, 40}
numbers.discard(30)      # Remove if present (no error) -> {10, 40}
print(numbers)           # {10, 40}
```

| Property | Value |
|---|---|
| Ordered | No |
| Mutable | Yes |
| Duplicates | No |
| Indexing | No |

**Set operations:**

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)      # Union                -> {1, 2, 3, 4, 5}
print(a & b)      # Intersection         -> {3}
print(a - b)      # Difference           -> {1, 2}
print(a ^ b)      # Symmetric difference -> {1, 2, 4, 5}
```

### Dictionaries

Purpose: store **key → value** pairs.

```python
student = {
    "name": "Ali",
    "age": 20,
    "grade": "A"
}


# Access
print(student["name"])           # Ali


# Add / Update
student["age"] = 21              # update an existing key
student["city"] = "Multan"       # add a new key


# Delete
student.pop("age")               # removes "age" and returns 21
del student["city"]              # removes "city"
print(student)                   # {'name': 'Ali', 'grade': 'A'}
```

**Important methods:**

```python
student = {"name": "Ali", "age": 20}

student.keys()                   # Get keys            -> dict_keys(['name', 'age'])
student.values()                 # Get values          -> dict_values(['Ali', 20])
student.items()                  # Get key-value pairs -> dict_items([('name', 'Ali'), ('age', 20)])
student.get("name")              # Get value           -> 'Ali'
student.get("phone", "N/A")      # Default if missing  -> 'N/A' (no KeyError)
student.update({"city": "Lahore"})   # Add/update data
student.pop("age")               # Remove an item      -> 20
student.clear()                  # Empty the dictionary -> {}
```

> **Tip:** `student["phone"]` raises a `KeyError` if the key does not exist, but `student.get("phone")` returns `None`.

### Collections Comparison

| Type | Syntax | Ordered | Mutable | Duplicates | Indexing |
|---|---|---|---|---|---|
| List | `[1, 2]` | Yes | Yes | Yes | Yes |
| Tuple | `(1, 2)` | Yes | No | Yes | Yes |
| Set | `{1, 2}` | No | Yes | No | No |
| Dictionary | `{"a": 1}` | Yes (Python 3.7+) | Yes | Keys: No | By key |

## Exceptions

### What Is an Exception?

An **exception** is an error that happens **while the program is running**. If it is not handled, the program stops.

```python
x = 10 / 0
# ZeroDivisionError: division by zero
```

### try

Put the risky code inside the `try` block.

```python
try:
    x = 10 / 0
# A try block must be followed by at least one except or finally block,
# otherwise Python raises a SyntaxError.
```

### except

`except` handles the exception.

```python
try:
    x = 10 / 0

except ZeroDivisionError:
    print("Cannot divide by zero")   # Cannot divide by zero
```

### Handling Multiple Exceptions

```python
try:
    number = int(input("Enter a number: "))
    result = 10 / number

except ValueError:
    # Runs if the input cannot be converted to int (e.g. "abc")
    print("Please enter a valid number")

except ZeroDivisionError:
    # Runs if the user enters 0
    print("Cannot divide by zero")
```

### else

`else` runs **only when no exception occurs**.

```python
try:
    number = int(input("Enter number: "))

except ValueError:
    print("Invalid input")

else:
    print("Valid number:", number)
```

### finally

`finally` **always** runs, whether an exception occurs or not. It is often used for clean-up (closing files, connections).

```python
try:
    print("Running program")

except Exception:
    print("Error occurred")

finally:
    print("Program finished")

# Output:
# Running program
# Program finished
```

### Complete Exception Structure

```python
try:
    # Risky code
    number = int(input("Enter number: "))

except ValueError:
    # Handle the error
    print("Invalid input")

else:
    # Runs if there is NO error
    print("Input is valid")

finally:
    # Always runs
    print("Finished")
```

### Getting Error Details with as

`as e` stores the exception object in a variable so you can see its message.

```python
try:
    number = int("abc")

except ValueError as e:
    print(e)   # invalid literal for int() with base 10: 'abc'
```

### raise

`raise` manually triggers an exception.

```python
age = -5

if age < 0:
    raise ValueError("Age cannot be negative")
# ValueError: Age cannot be negative
```

### Custom Exceptions

Create your own exception type by inheriting from `Exception`.

```python
class MyError(Exception):
    pass

try:
    raise MyError("Something went wrong")
except MyError as e:
    print("Caught:", e)   # Caught: Something went wrong
```

### Common Built-in Exceptions

| Exception | When it happens | Example |
|---|---|---|
| `ZeroDivisionError` | Dividing by zero | `10 / 0` |
| `ValueError` | Right type but wrong value | `int("abc")` |
| `TypeError` | Wrong type for an operation | `"Age: " + 20` |
| `NameError` | Variable is not defined | `print(y)` |
| `IndexError` | Index out of range | `[1, 2][5]` |
| `KeyError` | Dictionary key not found | `{"a": 1}["b"]` |
| `FileNotFoundError` | File does not exist | `open("missing.txt")` |
| `AttributeError` | Object has no such attribute | `(5).upper()` |
| `ImportError` / `ModuleNotFoundError` | Module cannot be imported | `import notamodule` |

> **Tip:** Catch **specific** exceptions (like `ValueError`) instead of a bare `except:`, so you do not hide unexpected bugs.

## File Handling

File handling lets you **store** data permanently in files and **retrieve** it later.

### Opening a File

```python
# Syntax: open(filename, mode)
file = open("data.txt", "r")   # open a file for reading
```

### Closing a File

```python
file.close()   # close the file after using it
```

> **Tip:** Prefer `with open(...) as file:`. Python then closes the file automatically, even if an error happens.

### Reading the Entire File

```python
with open("data.txt", "r") as file:
    data = file.read()   # the complete file as ONE string

print(data)
```

### Reading One Line

```python
with open("data.txt", "r") as file:
    line = file.readline()   # reads the next line (including its \n)

print(line)
```

### Reading All Lines

```python
with open("data.txt", "r") as file:
    lines = file.readlines()   # all lines in a LIST

print(lines)   # e.g. ['Python\n', 'Java\n', 'C++\n']
# Each line keeps its newline character (\n). Use line.strip() to remove it.
```

### Looping Through a File

Process a file line by line. Useful for large files because only one line is in memory at a time.

```python
with open("data.txt", "r") as file:
    for line in file:
        print(line.strip())   # strip() removes the extra \n
```

### Writing to a File

```python
with open("data.txt", "w") as file:
    file.write("Hello Python")

# "w" OVERWRITES the existing content (and creates the file if needed).
```

### Writing Multiple Lines

```python
with open("data.txt", "w") as file:
    file.write("Python\n")
    file.write("Java\n")
    file.write("C++\n")

# \n = new line
```

### writelines()

```python
lines = [
    "Python\n",
    "Java\n",
    "C++\n"
]

with open("data.txt", "w") as file:
    file.writelines(lines)

# Writes a list of strings.
# writelines() does NOT add \n automatically - include it yourself.
```

### Appending to a File

```python
with open("data.txt", "a") as file:
    file.write("\nNew data")

# "a" adds data to the END of the file and keeps the old content.
```

### Creating a New File

```python
with open("new.txt", "x") as file:
    file.write("Hello")

# "x" creates a new file.
# It raises FileExistsError if the file already exists.
```

### File Encoding

```python
with open("data.txt", "r", encoding="utf-8") as file:
    data = file.read()

# encoding tells Python how text is stored as bytes.
# UTF-8 supports almost all characters and languages (e.g. Urdu, Arabic, emoji)
# and is the most common choice for text files.
```

> **Tip:** Always pass `encoding="utf-8"` for text files. On Windows the default encoding may be different, which can cause `UnicodeDecodeError`.

### File Position with tell()

```python
with open("data.txt", "r") as file:
    print(file.tell())   # 0 - the current position (at the start)
    file.read(5)         # read 5 characters
    print(file.tell())   # 5
```

### File Position with seek()

```python
with open("data.txt", "r") as file:
    file.read()          # the position is now at the end
    file.seek(0)         # move back to the beginning
    data = file.read()   # read the whole file again

# seek(0) -> beginning of the file
```

### File Error Handling

Prevent the program from crashing when the file cannot be found.

```python
try:
    with open("missing.txt", "r") as file:
        data = file.read()

except FileNotFoundError:
    print("File does not exist")
```

### pathlib

`pathlib` is the modern and convenient way to work with paths and files.

```python
from pathlib import Path

path = Path("data.txt")

print(path.exists())   # True or False
print(path.suffix)     # .txt
print(path.stem)       # data

# Write
path.write_text("Hello", encoding="utf-8")

# Read
data = path.read_text(encoding="utf-8")
print(data)            # Hello

# Join paths safely (works on Windows, macOS and Linux)
folder = Path("project") / "data" / "file.csv"
```

### Binary Files

```python
with open("image.jpg", "rb") as file:   # rb = read binary
    data = file.read()                  # data is of type bytes
```

Binary mode is used for:
- Images
- Audio

## Regular Expressions

A **regular expression (regex)** is a pattern used to search, extract, validate or replace text. Python's built-in `re` module handles regex.

> **Tip:** Always write patterns as **raw strings** (`r"\d+"`), so backslashes are not treated as escape characters.

### Main re Functions

| Function | Purpose | Returns |
|---|---|---|
| `re.search()` | Find the first match anywhere | Match object or `None` |
| `re.match()` | Match only at the beginning | Match object or `None` |
| `re.fullmatch()` | The whole string must match | Match object or `None` |
| `re.findall()` | Find all matches | List of strings |
| `re.finditer()` | Find all matches with positions | Iterator of Match objects |
| `re.sub()` | Replace matches | New string |
| `re.split()` | Split by a pattern | List of strings |
| `re.compile()` | Save a pattern for reuse | Pattern object |

### Searching and Matching

```python
import re

# SEARCH - find the first match
text = "Student age is 21"

match = re.search(r"\d+", text)

if match:
    print(match.group())   # 21


# MATCH - check the beginning of the string
print(bool(re.match(r"Student", text)))   # True
print(bool(re.match(r"age", text)))       # False - "age" is not at the start


# FULLMATCH - validate the entire string
print(bool(re.fullmatch(r"\d{5}", "12345")))    # True
print(bool(re.fullmatch(r"\d{5}", "123456")))   # False
```

### Finding All Matches

```python
# FINDALL - extract all matches
print(re.findall(r"\d+", "A10 B20 C30"))
# ['10', '20', '30']


# FINDITER - extract matches and their positions
for match in re.finditer(r"\d+", "A10 B20"):
    print(match.group(), match.span())

# Output:
# 10 (1, 3)
# 20 (5, 7)
```

### Replacing and Splitting

```python
# SUB - replace / clean text
print(re.sub(r"\s+", " ", "Python   Data   Science"))
# 'Python Data Science'


# SPLIT - split on multiple delimiters
print(re.split(r"[,;]\s*", "Python, Java; C++"))
# ['Python', 'Java', 'C++']
```

### Compiling a Pattern

```python
# COMPILE - reusable pattern (faster when used many times)
pattern = re.compile(r"\d+")
print(pattern.findall("A10 B20"))
# ['10', '20']
```

### Groups and Named Groups

```python
# GROUPS - extract parts of a date with ( )
match = re.search(
    r"(\d{4})-(\d{2})-(\d{2})",
    "2026-09-29"
)

if match:
    print(match.group(0))  # 2026-09-29 (full match)
    print(match.group(1))  # 2026 (year)
    print(match.group(2))  # 09   (month)
    print(match.group(3))  # 29   (day)


# NAMED GROUPS - structured extraction with (?P<name>...)
pattern = r"(?P<year>\d{4})-(?P<month>\d{2})"

match = re.search(pattern, "2026-09")

if match:
    print(match.groupdict())      # {'year': '2026', 'month': '09'}
    print(match.group("year"))    # 2026
```

### Flags and Word Boundaries

```python
# IGNORE CASE - re.I (or re.IGNORECASE)
print(re.findall(r"python", "Python PYTHON", re.I))
# ['Python', 'PYTHON']


# WORD BOUNDARY - \b matches only complete words
print(re.findall(r"\bcat\b", "cat category cat"))
# ['cat', 'cat']   ("category" is not matched)
```

### Practical Examples

```python
# EXTRACT EMAILS - simple pattern
email_pattern = r"[\w.+-]+@[\w.-]+\.[A-Za-z]{2,}"

print(re.findall(email_pattern, "Email: ali@example.com"))
# ['ali@example.com']


# EXTRACT NUMBERS - integers and decimals
print(re.findall(r"\d+(?:\.\d+)?", "Price: 25.50, Qty: 3"))
# ['25.50', '3']
# (?:...) is a non-capturing group, so findall returns the full match


# CLEAN TEXT - remove punctuation
print(re.sub(r"[^\w\s]", "", "Hello!!! Python@@"))
# 'Hello Python'
```

### Common Pattern Symbols

| Symbol | Meaning | Example | Matches |
|---|---|---|---|
| `\d` | Any digit (0-9) | `\d+` | `2026` |
| `\D` | Any non-digit | `\D+` | `abc` |
| `\w` | Letter, digit or `_` | `\w+` | `data_1` |
| `\W` | Not a word character | `\W` | `@` |
| `\s` | Whitespace (space, tab, newline) | `\s+` | `"   "` |
| `.` | Any character except newline | `a.c` | `abc`, `a-c` |
| `^` | Start of string | `^Hi` | `Hi there` |
| `$` | End of string | `end$` | `the end` |
| `*` | 0 or more | `ab*` | `a`, `abbb` |
| `+` | 1 or more | `ab+` | `ab`, `abbb` |
| `?` | 0 or 1 (optional) | `colou?r` | `color`, `colour` |
| `{n}` / `{n,m}` | Exactly n / between n and m | `\d{4}` | `2026` |
| `[abc]` | Any one of these characters | `[aeiou]` | `e` |
| `[^abc]` | Any character NOT in the set | `[^0-9]` | `x` |
| `a\|b` | `a` or `b` | `cat\|dog` | `dog` |
| `( )` | Capturing group | `(\d+)-(\d+)` | `10-20` |
| `\b` | Word boundary | `\bcat\b` | `cat` (not `category`) |

## Imports and Modules

- A **module** is a Python file (`.py`) containing reusable code (functions, classes, variables).
- A **package** is a folder of modules.

```python
# General forms
import package_or_module
from package import module
```

### Importing Modules

```python
# Import a complete module
import math
print(math.sqrt(25))   # 5.0

# Import a specific item
from math import sqrt
print(sqrt(25))        # 5.0

# Import multiple items
from math import sqrt, pi

# Import a module with an alias (short name)
import math as m
print(m.sqrt(25))      # 5.0

# Import an item with an alias
from math import sqrt as s
print(s(25))           # 5.0
```

> **Tip:** Common Data Science aliases: `import numpy as np`, `import pandas as pd`, `import matplotlib.pyplot as plt`. Avoid `from module import *` - it makes it unclear where names come from.

### Creating Your Own Module

Any `.py` file can be imported by another file in the same folder.

```python
# calculator.py
def add(a, b):
    return a + b
```

```python
# main.py (in the same folder)
import calculator
print(calculator.add(5, 3))   # 8
```

### Running a File Directly

```python
# Check if the file is run directly
if __name__ == "__main__":
    print("Program started")
```

> **Important Point:** The code under `if __name__ == "__main__":` runs when the file is **executed directly** (`python calculator.py`), but **not** when the file is imported by another file.

## pip

`pip` is the Python package installer. It downloads packages from PyPI (https://pypi.org).

```bash
# Install a package
pip install package_name

# Install a specific version
pip install requests==2.32.0

# Upgrade a package
pip install --upgrade package_name

# Uninstall a package
pip uninstall package_name

# Show all installed packages
pip list

# Show information about a package
pip show package_name

# Check outdated packages
pip list --outdated

# Save installed packages to requirements.txt
pip freeze > requirements.txt

# Install packages from requirements.txt
pip install -r requirements.txt
```

> **Tip:** `python -m pip install package_name` makes sure the package is installed for the same Python you are running.
